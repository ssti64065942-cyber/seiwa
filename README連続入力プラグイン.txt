# 連続入力プラグイン

## 概要

kintoneのレコード保存後、指定したフィールドの値を保持して連続入力を可能にするプラグインです。

### 主な機能
- レコード保存後に同じ値を保持して新規作成画面に自動遷移
- 保持するフィールドを柔軟に選択可能
- チェックボックスで連続入力のON/OFF切り替え
- 初期状態で連続入力がON（デフォルト有効）

## インストール方法

### 1. プラグインのパッケージング

PowerShellで以下のコマンドを実行：
```powershell
# 初回作成時
npx @kintone/plugin-packer "プラグインフォルダのパス"

# 更新時（秘密鍵を使用）
npx @kintone/plugin-packer --ppk "秘密鍵.ppk" "プラグインフォルダのパス"
```

**例:**
```powershell
# 初回
npx @kintone/plugin-packer "C:\Users\PC122\Documents\Visual Studio Code\キントーン作成物\連続入力プラグイン\version1.0"

# 更新時
npx @kintone/plugin-packer --ppk "C:\...\version1.0\生成されたプラグインID.ppk" "C:\...\version1.0"
```

### 2. プラグインのインストール
1. kintoneのシステム管理画面を開く
2. 「プラグイン」をクリック
3. 「読み込む」から生成された `plugin.zip` をアップロード

### 3. アプリへの追加
1. 対象のアプリの設定画面を開く
2. 「設定」→「プラグイン」
3. インストールしたプラグインを追加

## プラグイン設定

### 設定画面の開き方
1. アプリの設定画面を開く
2. 「プラグイン」タブ
3. 「連続入力プラグイン」の歯車アイコンをクリック

### 設定項目

#### 保持するフィールドの設定

レコード保存後に値を保持したいフィールドを選択します。複数のフィールドを設定可能です。

| 項目 | 必須 | 説明 |
|------|------|------|
| **フィールド選択** | ○ | 値を保持したいフィールドをプルダウンから選択 |

#### 操作
- **＋ フィールドを追加**: 新しいフィールド選択行を追加
- **−**: 該当する選択行を削除
- **保存**: 設定を保存してプラグイン設定画面に戻る
- **キャンセル**: 設定を保存せずにプラグイン設定画面に戻る

### 設定例
```
保持するフィールド:
  担当者
  + フィールドを追加

  部署
  + フィールドを追加

  プロジェクト名
  + フィールドを追加
```

### ⚠️ 注意事項
**重複禁止が設定されたフィールドを選択すると、保存エラーになる可能性があります。**

重複禁止フィールド（自動採番、管理番号など）は保持対象から除外してください。

## 使用方法

### 1. 初期設定
1. プラグインをアプリに追加
2. プラグイン設定画面で保持したいフィールドを選択
3. 設定を保存
4. アプリを更新

### 2. 連続入力の実行

#### 基本的な流れ
1. レコード作成画面を開く
2. ヘッダー部分に「**保存後に続けて入力する**」チェックボックスが表示される（デフォルトでON）
3. 必要な情報を入力
4. 「保存」ボタンをクリック
5. 自動的に新しいレコード作成画面に遷移
6. 設定したフィールドの値が自動的に復元される
7. 手順3〜6を繰り返し

#### 連続入力を終了する場合
- チェックボックスをOFFにして保存
- または「キャンセル」ボタンをクリック

### 使用例

**シナリオ**: 同じ担当者で複数の案件レコードを連続登録

```
【1件目】
担当者: 山田太郎 ← 保持される
部署: 営業部 ← 保持される
案件名: A社新規提案
☑ 保存後に続けて入力する

↓ 保存

【2件目（自動遷移）】
担当者: 山田太郎 ← 自動入力済み
部署: 営業部 ← 自動入力済み
案件名: [空欄] ← 新規入力
☑ 保存後に続けて入力する

↓ 保存

【3件目（自動遷移）】
担当者: 山田太郎 ← 自動入力済み
部署: 営業部 ← 自動入力済み
案件名: [空欄] ← 新規入力
☐ 保存後に続けて入力する ← OFFにして終了

↓ 保存 → 一覧画面に戻る
```

## 技術仕様

### 対応フィールドタイプ

以下のフィールドタイプに対応しています：

| カテゴリ | フィールドタイプ |
|---------|----------------|
| **テキスト** | 文字列（1行） |
| **数値** | 数値 |
| **日時** | 日付、時刻、日時 |
| **選択** | ドロップダウン、ラジオボタン、チェックボックス、複数選択 |
| **ユーザー/組織** | ユーザー選択、組織選択、グループ選択 |

### 非対応フィールドタイプ

以下のフィールドは本プラグインでは対応していません：

- 添付ファイル
- テーブル
- リッチエディタ
- 関連レコード一覧
- ルックアップ（値は保持されますが自動取得は実行されません）

### 使用API・技術

| API/技術 | 用途 |
|---------|------|
| `kintone.plugin.app.getConfig()` | プラグイン設定取得 |
| `kintone.plugin.app.setConfig()` | プラグイン設定保存 |
| `kintone.api()` | フィールド情報取得 |
| `kintone.events.on()` | イベント登録 |
| `sessionStorage` | 値の一時保存 |

### イベントハンドリング

| イベント | 処理内容 |
|---------|---------|
| `app.record.create.show` | チェックボックス表示、値の復元 |
| `app.record.create.submit.success` | 値の保存、画面遷移 |
| `app.record.create.cancel` | ストレージのクリア |
| `app.record.index.show` | ストレージのクリア |

## トラブルシューティング

### Q1: チェックボックスが表示されない
**A**: 以下を確認してください：
- プラグインが正しくインストールされているか
- アプリが更新されているか
- プラグイン設定で少なくとも1つ以上のフィールドが選択されているか
- ブラウザのキャッシュをクリアして再読み込み

### Q2: 値が復元されない
**A**: 以下を確認してください：
- チェックボックスがONになっているか
- プラグイン設定で保持したいフィールドが正しく選択されているか
- ブラウザのSessionStorageが有効か（プライベートブラウジングモードでは無効の場合あり）
- ブラウザの開発者ツール（F12）のConsoleタブでエラーが出ていないか

### Q3: 保存時にエラーが発生する
**A**: 以下を確認してください：
- 重複禁止フィールド（自動採番など）が保持対象になっていないか
- 必須フィールドが適切に入力されているか
- フィールドの入力値が妥当な値か（数値フィールドに文字列など）

### Q4: 連続入力が終わらない
**A**: 以下の方法で終了できます：
- チェックボックスをOFFにして保存
- 「キャンセル」ボタンをクリック
- ブラウザの戻るボタンで一覧画面に戻る

### Q5: 設定画面でフィールドが選択できない
**A**: 以下を確認してください：
- アプリに対応フィールドタイプのフィールドが存在するか
- ブラウザの開発者ツールのConsoleタブでエラーが出ていないか

### デバッグ方法
1. ブラウザの開発者ツールを開く（F12キー）
2. 「Console」タブを選択
3. エラーメッセージやログを確認
4. プラグイン設定画面では、各ボタンクリック時にログが出力されます

**デバッグログの例:**
```
プラグイン設定画面を初期化中...
PLUGIN_ID: abcdefghijklmnopqrstuvwxyz
フィールド追加ボタンが見つかりました
保存ボタンが見つかりました
キャンセルボタンが見つかりました
フィールド情報を取得しました: Array(15)
```

## 制限事項

### 機能制限
- レコード作成画面でのみ動作（編集画面では動作しません）
- 添付ファイル、テーブル、リッチエディタなどの複雑なフィールドは非対応
- ルックアップフィールドは値のみ保持（自動取得は実行されません）
- レコード一覧画面からの一括操作には非対応

### データ保持制限
- 値の保持にSessionStorageを使用（ブラウザを閉じると消去）
- プライベートブラウジングモードでは動作しない場合あり
- 異なるブラウザ/タブ間では値は共有されない

### セキュリティ制限
- 保持される値はブラウザのSessionStorageに一時保存されます
- 保存された値は同一タブ内でのみ有効

---

## セキュリティ

### アクセス制御
- プラグインはユーザーの権限で動作
- アプリの閲覧・追加権限がないユーザーは使用不可

### データ処理
- すべての処理はクライアント（ブラウザ）側で実行
- データは外部サーバーに送信されない
- SessionStorageに一時保存された値は、保存後またはキャンセル時に自動削除

### プライバシー
- 保持される値は個人のブラウザ内のみに保存
- 他のユーザーには共有されない

## ベストプラクティス

### 推奨される使い方

#### ✅ 良い使い方
- 同じ担当者で複数の案件を登録
- 同じカテゴリで複数の商品を登録
- 同じ日付で複数のタスクを登録
- 定期的なレポート入力（日報、週報など）

#### ❌ 避けるべき使い方
- 自動採番フィールドを保持対象にする
- 重複禁止フィールドを保持対象にする
- すべてのフィールドを保持対象にする（必要なものだけ選択）

### 効率的な設定

1. **頻繁に同じ値を入力するフィールドのみ保持**
   - 担当者、部署、カテゴリなど
   - レコードごとに変わる値（件名、詳細など）は保持しない

2. **重複禁止フィールドは除外**
   - 管理番号、伝票番号などは保持対象から除外

3. **必須フィールドは慎重に選択**
   - 必須フィールドを保持すると便利だが、変更を忘れないよう注意

## よくある質問（FAQ）

### Q: 編集画面でも使えますか？
**A**: いいえ、現在のバージョンではレコード作成画面のみ対応しています。

### Q: チェックボックスの初期状態をOFFにできますか？
**A**: はい、`js/desktop.js`の該当箇所を修正することで変更可能です。詳細は開発者にお問い合わせください。

### Q: 保持する値はどこに保存されますか？
**A**: ブラウザのSessionStorageに一時保存されます。ブラウザを閉じると自動的に削除されます。

### Q: 複数のユーザーで値が共有されますか？
**A**: いいえ、各ユーザーのブラウザ内でのみ保存され、他のユーザーには共有されません。

### Q: ルックアップフィールドは使えますか？
**A**: 値は保持されますが、ルックアップの自動取得は実行されません。必要に応じて手動で再取得してください。
