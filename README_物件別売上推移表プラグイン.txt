物件別売上推移表プラグイン 仕様書概要kintoneアプリに蓄積された売上データを、物件別・年度別に集計し、Excel形式の推移表として出力するプラグインです。最大3期（当期・前期・前々期）の数値を並べて比較することが可能です。主な機能1. 3期分の売上推移を表示指定した年度（対象年度）から過去3年分（当期・前期・前々期）のデータを自動取得。物件ごとに3行（当期・前期・前々期）のデータを出力し、年度間の比較を容易にします。2. 複数行の集計（グループ化機能）1つの物件×年度に対して、複数の指標（売上、原価、粗利など）を個別に行として出力可能。設定画面で「集計項目名（グループ）」を共通化することで、自由度の高い帳票レイアウトを作成できます。3. 高度なExcelレイアウトフォント: 帳票全体に「游ゴシック」を適用し、ビジネスシーンに適した視認性を確保。罫線: 物件ごとの区切りを太線、年度間の区切りを点線で表現し、データの見やすさを向上。セル結合: 物件名や追加ヘッダー情報を垂直方向に自動結合。動的カラム: 物件コードの表示/非表示、物件名ラベルのカスタマイズに対応。4. 柔軟な検索・フィルタリング出力時に物件名でのフィルタリングが可能。追加の検索条件（カテゴリー、担当者など）を指定して出力を絞り込むことができます。プラグイン設定項目アプリ設定物件マスタアプリ: 物件情報を管理しているアプリを選択。売上詳細アプリ: 実際の売上レコードが保存されているアプリを選択。表示設定年度開始月: 決算期などに合わせて、集計の開始月（1〜12月）を設定。物件コードの表示: Excel出力時に物件コード列を含めるかどうか。物件名ラベル: 「店舗名」「拠点名」など、帳票上の見出しをカスタマイズ。追加ヘッダー: 物件マスタから取得して帳票に表示したい項目（住所、管理区分など）を最大5つまで設定可能。集計項目マッピング集計項目名（グループ）: Excel上の行名（例：「売上合計」）。フィールドコード: 集計対象となる数値フィールド。加算/減算: 売上から原価を引くなどの計算ロジックを設定。使用方法1. 事前準備物件情報を管理する「物件マスタアプリ」を用意します。日々の売上を記録する「売上レコードアプリ」を用意します（日付と物件紐付けキーが必須）。2. 設定プラグインの設定画面で、各アプリのIDとフィールドコード、集計ルールを保存します。3. 出力アプリ一覧画面の上部に表示される「📈 売上推移表出力」ボタンをクリックします。ポップアップで「対象年度」を選択し、必要に応じてフィルタリング条件を指定します。「実行」をクリックすると、集計されたExcelファイルがダウンロードされます。注意事項データ量: 3年分の大量データを取得するため、物件数やレコード数が多い場合は出力に時間がかかる場合があります。権限: 実行するユーザーに、売上レコードアプリおよび物件マスタアプリの閲覧権限が必要です。📊 バージョン情報項目	内容バージョン	1.0更新日	2026年2月18日作成者	稲富対象	PC版Kintone
