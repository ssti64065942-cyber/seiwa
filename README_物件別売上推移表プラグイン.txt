# 物件別売上推移表プラグイン 仕様書

## 概要

kintoneアプリに蓄積された売上データを、物件別・年度別に集計し、Excel形式の推移表として出力するプラグインです。最大3期（当期・前期・前々期）の数値を並べて比較することが可能です。

## 主な機能

### 1. 3期分の売上推移を表示
- 指定した年度（対象年度）から過去3年分（当期・前期・前々期）のデータを自動取得。
- 物件ごとに年度別のデータを出力し、さらに当期と前期については各項目の直下に「(前期比)」行を挿入することで、詳細な成長率分析を可能にします。

### 2. インデックス形式の比較レイアウト
- 項目ごとに実績値と前期比を並べて表示するインデックス形式を採用。
- スクロールすることなく、各項目の対前年比をその場で確認できる視認性の高いレイアウトです。

### 3. 高度なExcelレイアウト
- **視認性の向上**: 前期比のラベルや数値は黒色で表示し、ビジネス帳票としての読みやすさを確保。
- **フォント**: 帳票全体に「游ゴシック」を適用。
- **罫線表現**: 物件ごとの境界を太線(medium)、年度や項目の区切りを点線(dotted)で使い分け。
- **セル結合**: 物件名、追加ヘッダー情報、年度ラベルを垂直方向に自動結合。
- **動的な設定**: 物件コードの表示/非表示、物件名ラベル（「店舗名」等）のカスタマイズに対応。

### 4. 柔軟な検索・フィルタリング
- 出力時に物件名や物件コードでの絞り込みが可能。
- 設定画面で指定した追加フィールド（住所、担当者など）による動的なフィルタリングに対応。

## プラグイン設定項目

### アプリ設定
- **物件マスタアプリ**: 物件情報を管理しているアプリを選択。
- **売上詳細アプリ**: 実際の売上レコードが保存されているアプリを選択。

### 表示設定
- **年度開始月**: 決算期などに合わせて、集計の開始月（1〜12月）を設定。
- **物件コードの表示**: Excel出力時に物件コード列を含めるかどうか。
- **物件名ラベル**: 「店舗名」「拠点名」など、帳票上の見出しをカスタマイズ。
- **追加ヘッダー**: 物件マスタから取得して帳票に表示したい項目を最大5つまで設定可能。

### 集計項目マッピング
- **集計項目名（グループ）**: Excel上の行名（例：「売上合計」）。
- **フィールドコード**: 集計対象となる数値フィールド。
- **加算/減算**: 売上から原価を引くなどの計算ロジックを設定。

## 使用方法

### 1. 出力開始
- アプリ一覧画面の上部に表示される「📈 売上推移表出力」ボタンをクリックします。

### 2. 対象指定
- ポップアップで「対象年度」を選択し、必要に応じてフィルタリング条件を指定します。

### 3. 実行
- 「実行」をクリックすると、集計されたExcelファイルがダウンロードされます。

## 注意事項
- **データ量**: 3年分の大量データを取得するため、物件数やレコード数が多い場合は出力に時間がかかる場合があります。
- **権限**: 実行するユーザーに、売上レコードアプリおよび物件マスタアプリの閲覧権限が必要です。
