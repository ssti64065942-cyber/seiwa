# 科目別合計表示プラグイン 仕様書

## 概要

Kintone の一覧画面で科目別の合計金額をリアルタイムに表示するプラグインです。

## 主な機能

-   一覧画面で科目別の合計金額を表示
-   プラグイン設定画面から集計項目を柔軟に設定可能
-   総合計とは別に個別集計フィールドを設定可能
-   単位のカスタマイズ（¥、円など前後に設定可能）
-   絞り込み条件に応じた自動再計算
-   最小化/最大化機能
-   表示位置のカスタマイズ（4箇所から選択）
-   カラーテーマの選択（4種類）
-   総合計・レコード件数の表示/非表示切り替え

## プラグイン設定項目

### 基本設定

-   **表示位置**: 合計表示エリアの位置を選択（右上/左上/右下/左下）
-   **絞り込み時に自動更新**: 絞り込み条件変更時に自動で再計算
-   **初期状態で最小化**: 一覧表示時に最小化状態で表示

### 単位設定

-   **前置単位**: 金額の前に表示する単位（例: ¥、$）
-   **後置単位**: 金額の後に表示する単位（例: 円、USD）
-   プレビュー機能で表示イメージを確認可能

### 集計項目設定

1.  「➕ 項目を追加」ボタンをクリック
2.  **表示名**: 集計項目の名前を入力（例: 時間貸し、月極）
3.  **集計フィールド**: 合計する数値フィールドを選択
4.  必要な項目数だけ追加
5.  不要な項目は「✕ 削除」ボタンで削除

### 個別集計設定

総合計とは別に表示したい個別の集計項目を設定します。

1.  「➕ 個別集計を追加」ボタンをクリック
2.  **表示名**: 個別集計の名前を入力（例: 特別割引、手数料）
3.  **集計フィールド**: 集計する数値フィールドを選択
4.  総合計の下に独立して表示されます

### 表示設定

-   **集計レコード数を表示**: 集計対象のレコード数を表示
-   **総合計を表示**: すべての科目の合計を表示
-   **カラーテーマ**: 表示色を選択（ブルー/グリーン/オレンジ/パープル）

## 対応フィールドタイプ

以下のフィールドタイプに対応しています：

-   数値フィールド
-   計算フィールド（数値）

## 使用方法

### インストール方法

1.  以下のファイル構成でフォルダを作成
2.  `image/icon.png` を用意（48x48pxのPNG画像）
3.  フォルダをZIPファイルに圧縮
4.  kintone 管理画面から「プラグイン」→「読み込む」でZIPファイルをアップロード
5.  アプリの設定画面でプラグインを追加

### 初期設定

1.  プラグインをアプリにインストール後、アプリの設定画面でプラグイン設定を開きます。
2.  基本設定、単位設定、集計項目設定、個別集計設定、表示設定の各項目を設定します。
3.  設定完了後、「保存」ボタンをクリックし、アプリを更新します。

### 使用例

#### 駐車場管理アプリの場合

**単位設定:**
- 前置単位: `¥`
- 後置単位: (空欄)

**集計項目設定:**
- 項目1: 表示名「時間貸し」/ フィールド「数値_時間貸し」
- 項目2: 表示名「月極」/ フィールド「数値_月極」
- 項目3: 表示名「電子マネー」/ フィールド「数値_電子マネー」
- 項目4: 表示名「プリペイド」/ フィールド「数値_プリペイド」

**個別集計設定:**
- 個別集計1: 表示名「特別割引」/ フィールド「数値_割引」

**表示例:**
```
📊 科目別合計
━━━━━━━━━━━━━━━━
時間貸し        ¥125,000
月極           ¥450,000
電子マネー       ¥35,000
プリペイド       ¥18,000
━━━━━━━━━━━━━━━━
総合計         ¥628,000
特別割引        ¥12,500
集計レコード数: 145件
```

#### 単位設定の例

**日本円の場合:**
- 前置: `¥` / 後置: (空欄) → `¥123,456`
- 前置: (空欄) / 後置: `円` → `123,456円`
- 前置: `¥` / 後置: `円` → `¥123,456円`

**米ドルの場合:**
- 前置: `$` / 後置: (空欄) → `$123,456`
- 前置: (空欄) / 後置: `USD` → `123,456USD`

## 注意事項

-   一覧画面で最大500件ずつレコードを取得します
-   絞り込み条件が設定されている場合、その条件に応じた合計を表示します
-   数値以外のフィールドは集計対象外です
-   プラグイン設定を変更した場合は、アプリを更新してください

## トラブルシューティング

### 合計が表示されない

-   プラグイン設定で集計項目が正しく設定されているか確認
-   フィールドコードが正確か確認
-   ブラウザのコンソールログを確認

### 合計が正しくない

-   絞り込み条件を確認
-   「🔄 再計算」ボタンをクリックして再計算

### 設定画面でフィールドが表示されない

-   アプリに数値フィールドまたは計算フィールドがあるか確認
-   ブラウザをリロードして再試行

## サポート

エラーが発生した場合は、ブラウザの開発者ツール（F12）でコンソールログを確認し、エラー内容を記録してください。
