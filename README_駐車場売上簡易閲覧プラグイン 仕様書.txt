# 駐車場売上簡易閲覧プラグイン 仕様書

## 概要
kintoneアプリ（売上レコードアプリ・アプリID: 155）のトップ画面（レコード一覧画面）に「📊 駐車場売上簡易閲覧」ボタンを追加し、物件ごとの年度累計（既定：当年度の期首〜最新月。年度プルダウンで切替可）の売上実績、1車室当たり売上、1台当たり単価、さらに**年度の売上目標に対する達成率・進捗率**をポップアップ画面上で直感的に閲覧・比較分析できるプラグインです。
マスタアプリ（駐車場情報・アプリID: 148）および売上指標マスタアプリと連携し、地域・市区町村・部署・担当者などでの柔軟な絞り込みや複数物件の選択比較、エリアごとの平均値比較、年度目標の達成状況把握をワンクリックで素早く行える環境を提供し、日々の売上把握と迅速な意思決定を強力にサポートします。

## 主な機能

### 1. 直感的な分析UI（売上アラート・物件別推移・地域別平均・目標達成率の4大ビュー）
- **対象年度の切り替え（v1.10.0）**:
  - 「🏆 売上アラート・比較」「📋 物件別推移」「🗾 地域・部署別」の3画面は、共通の **「対象年度」プルダウン** で年度単位に切り替えられます。起動時の既定は **当年度の期首〜最新の締まった月（年度累計）** です（過去年度は12か月）。従来の「直近3か月」「直近6か月」や月範囲指定は「対象期間」から引き続き選択できます。
  - 売上アラートの比較方法は **「期間累計 vs 前年同期（既定）」** と **「直近月 vs 直前2か月平均（従来）」** から選べます。期間累計では、選択期間（例: 2026年度 4月〜10月）の累計売上を前年の同じ月数と比較し、TOP・好調・ワーストを算出します。
- **🏆 売上アラート・推移比較モード（メインビュー）**:
  - 前月実績 vs 過去2か月平均の比較分析を行い、**「売上実績 TOP 5(10)」「好調物件 TOP 5(10)」「差額ワースト 5(10)」「急減ワースト 5(10)」** をメールと同様の色分けカード形式でリアルタイム表示します。
  - 左ペインの4大フィルター（都道府県・市区町村・部署・担当者）を変更すると、**その絞り込んだ条件の中での好調・不振ランキングと詳細推移表が瞬時に再計算**されます。
  - 下部には、全物件の詳細推移テーブル（前々月、前月、平均、当月、差額、増減率）を表示し、任意の列でソート可能。
  - **📥 CSV出力 / 📊 Excel出力ボタン**: 画面に表示されている絞り込み後のデータ一式をワンクリックでダウンロード可能です。特にExcel出力（`.xlsx`）では以下の**全7シート（売上指標マスタ連携時は全10シート）構成の総合分析レポート**（色分け・数値書式・太枠境界線・ウィンドウ枠固定付き）を1回のクリックで生成します：
    1. `ランキングサマリー`（総計＋TOP5/10・好調・差額ワースト・減少率ワースト）
    2. `詳細比較推移一覧`（合計行＋全件の前々月・前月・平均・当月・差額・増減率）
    3. `物件別推移`（合計＋各物件の全7指標・過去Nか月推移・最大青/最小赤）
    4. `都道府県別平均`（全体集計＋都道府県別の実数合計3指標＆物件平均7指標）
    5. `市区町村別平均`（全体集計＋市区町村別の実数合計3指標＆物件平均7指標）
    6. `管理部署別平均`（全体集計＋管理部署別の実数合計3指標＆物件平均7指標）
    7. `当社担当者別平均`（全体集計＋担当者別の実数合計3指標＆物件平均7指標）
    8. `目標達成率`（選択年度の物件別年間目標・実績累計・達成率・経過累計目標・月別推移明細）※指標マスタ設定時
    9. `目標達成率_部署別`（管理部署別の年間目標・実績・達成率・累計進捗）※指標マスタ設定時
    10. `目標達成率_担当者別`（当社担当者別の年間目標・実績・達成率・累計進捗）※指標マスタ設定時
- **🎯 目標達成率モード（v1.6.0〜v1.7.0）**:
  - 売上指標マスタアプリ（別プラグイン `kintone-plugin-parking-sales-target` で目標登録）を参照し、年度ごとの売上目標に対する達成率・進捗率を表示します（設定画面で売上指標マスタアプリが未設定の場合は本タブは非表示となり、従来機能のみ動作します）。
  - **ウィンドウ起動時の即時プリロード（v1.6.1）**: ウィンドウを開いた時点で当年度の売上目標レコードと年度売上レコードを一括取得するため、「🎯 目標達成率」タブへ切り替えた瞬間から待ち時間なしで閲覧できます。
  - **年度切り替え**: 開始年表記（例: `2026年度` = `2026/04/01 ～ 2027/03/31`）のプルダウンで年度を切り替えられます（既定は今日が属する年度）。対象年度の目標レコードが未登録の場合は「この年度の目標は未登録です」と表示します。
  - **左ペイン絞り込み＆個別チェックボックス除外・目標なしフィルター連動（v1.6.1〜v1.6.2）**:
    - 都道府県・市区町村・管理部署・当社担当者・キーワードを変更すると、対象物件の達成率が**即時再計算**されます（部署・担当者は現在の物件マスタ148の値を使用）。
    - 左ペインの物件一覧で特定の物件のチェックボックスを外すと、**5大サマリーカード・管理部署別集計・当社担当者別集計・物件別明細一覧・CSV/Excel出力のすべてからその物件が除外されて即時再計算**されます。
    - 左ペインの「**目標なしの物件を除外（目標ありのみ）**」「**目標なしの物件のみ表示**」チェックボックスにより、目標未設定物件の一括除外や目標未設定物件だけの抽出がワンクリックで行えます。
  - **売上指標マスタアプリの一括修正画面へのダイレクト連携（v1.7.0）**:
    - 明細一覧の年間目標列にある **`目標なし ✏️入力`** ボタン（または登録済み金額横の **`✏️`** ボタン）をクリックすると、別タブで売上指標マスタアプリが開き、**自動的に「🎯 年度目標を一括生成・一括修正」ウィンドウが起動して該当物件に絞り込まれた状態（年額入力欄に自動フォーカス）**で即座に目標を入力・修正できます。
    - 明細タイトル横の **`🎯 表示中の物件を目標管理で一括入力・修正（N件）`** ボタンをクリックすると、現在絞り込まれている複数物件（例：「目標なしの物件のみ表示」で抽出した全物件）をまとめて一括修正画面で開けます。
  - **5大サマリーカード**:
    - 年間目標（合計）
    - 当年度の実績累計（期首〜実績のある最新月まで）
    - 年間達成率（実績累計 ÷ 年間目標）
    - 年度末までの残り必要額
    - 経過月数時点の目標累計に対する進捗率（月別目標を累積して比較）
  - **部署別・担当者別の集計表**: 管理部署別および当社担当者別の年間目標・実績累計・達成率・経過月累計目標・累計達成率・差額を一覧表示（各列クリックでソート可能）。
  - **物件別明細表（独立スクロール＆左2列・2段ヘッダー固定対応 v1.6.3）**:
    - 列：物件コード、物件名、管理部署、担当者、年間目標、実績累計、達成率、累計目標（経過月まで）、累計達成率、差額、および月別12か月列（実績・月別目標・月ごとの達成率）。
    - 明細表のみを独立したスクロール枠に収め、横スクロール時に左2列（コード・物件名）を固定、縦スクロール時に2段ヘッダーが重ならず固定表示されます。
    - 達成率に応じた色分け表示（`100%以上` = 青、`80〜100%未満` = 黒、`80%未満` = 赤。しきい値は定数 `ACHIEVEMENT_THRESHOLDS` で定義）。
    - 目標未登録の物件は「目標なし ✏️入力」・達成率「－」と表示し、目標はあるが実績がない物件は実績 `0` として安全に表示します。
    - 任意の列ヘッダークリックまたは並び順プルダウンでソート可能。
    - 「📥 CSV出力」「📊 Excel出力」ボタンから目標達成率データをダウンロード可能。
  - **物件別明細一覧の全画面（フルウィンドウ）表示モード（v1.9.2）**:
    - ノートパソコン等の画面サイズでも明細一覧が埋もれず全体像を見渡せるよう、ツールバーおよび明細タイトル横に **`⛶ 明細全画面`** ボタンを追加。
    - クリックすると上部5大サマリーカード・管理部署別表・担当者別表および左サイドバーが一時的に非表示となり、明細一覧テーブルが画面全体（100%幅・100%高さ）にダイナミックに最大化展開されます。
    - 表の2段ヘッダー固定および左2列（コード・物件名）固定、任意列ソート、一括修正ボタン、SFAリンク等は全画面モード中もそのまま利用可能。
    - **`✕ 全画面を解除（元の全体表示に戻る）`** ボタンのクリック、またはキーボードの **`Esc` キー** を押すだけで、瞬時に通常の全体表示へ復帰します。
- **📋 物件別表示モード（ウィンドウ内での自由な期間選択・過去アプリ自動連携対応 v1.7.3）**:
  - 選択した物件ごとに、「売上金額(ALL)」「売上金額(月極抜)」「出庫台数」「1車室当たり(ALL)」「1車室当たり(月極抜)」「1台当たり単価(ALL)」「1台当たり単価(月極抜)」の全7指標を、指定期間の月別推移および期間平均（Nか月平均）で一覧表示します。
  - **ウィンドウ内での対象期間セレクター（v1.7.3）**:
    - ツールバーの「対象期間」から、プリセット（`直近3か月 ⚡即時`・`直近6か月 ⚡即時`・`当年度（4月〜最新月）⚡即時`・`直近12か月`・`前年度（12か月）`・`前々年度（12か月）`）または開始月〜終了月（`2020年1月`〜最新月、最大24か月幅）を自由に選択して表示期間を切り替えられます。
    - ウィンドウ起動時に当年度の売上データを一括プリロードしているため、`⚡` マーク付きの月範囲は **追加のAPIリクエスト0回（待ち時間0秒）** で即座に切り替わります。
    - `2026年3月` 以前の未取得月を含む期間を選択した場合のみ、不足月だけを過去売上アプリ（ID: `177`、`2020-01-01`〜`2026-03-31`）および現行売上アプリ（ID: `155`、`2026-04-01`〜）から自動差分取得してメモリにキャッシュ統合します（一度読み込んだ過去月も `⚡` マークが付き、以降は通信なしで即時切替可能）。
  - 複数物件（2件以上）を選択した場合は、表の最上部に「選択物件 合計」行が自動挿入され、選択対象全体の合算実績や車室当たり数値を一目で確認できます。
- **🗾 地域・部署別（合計・平均）モード（実数合計＋物件平均・サブタブ切替対応 v1.7.1〜v1.7.2）**:
  - 画面上部の「🗾 地域・部署別（合計・平均）」タブをクリックすると、上部に件数付きの4大サブタブボタン（**`🗾 都道府県別`**・**`🏙️ 市区町村別`**・**`🏢 管理部署別`**・**`👤 当社担当者別`**）が表示され、ワンクリックで集計単位を切り替えられます。
  - さらに表示切替ボタン（**`📊 合計＋平均（両方）`**・**`💰 合計（実数）のみ`**・**`📐 物件平均のみ`**）および上部の全体合計サマリーカード3種（売上金額(ALL)合計・売上金額(月極抜)合計・出庫台数合計）により、各グループの実数合計（`売上金額(ALL)【合計】`・`売上金額(月極抜)【合計】`・`出庫台数【合計】`）と物件平均（7指標）をひと目で比較できます（Excel出力の4シートにも合計3指標＋物件平均7指標の計10行が出力されます）。
  - 「📋 物件別推移」と同様に対象期間セレクターで任意の月範囲・年度へ切り替え可能です。
- **最大値（青）・最小値（赤）の自動カラーリング**:
  - 過去3か月の推移の中で、月ごとの最高実績を「青文字（太字）」、最低実績を「赤文字（太字）」で自動強調表示し、好不調の傾向を瞬時に把握できます。
- **視認性を高めた境界線レイアウト**:
  - 物件と物件の境目に太い黒境界線（3px）を配置し、行数の多い帳票でも物件の切り替わりが明確で直感的に読み取れます。

### 2. 柔軟な絞り込み・複数選択・検索機能
- **連動マルチフィルター（都道府県・市区町村・管理部署・当社担当者）**:
  - 「都道府県（地域）」「市区町村」「管理部署」「当社担当者」の各ドロップダウンを搭載。他の条件で絞り込んだ結果に応じて選択肢と件数がリアルタイムに連動します。
  - 都道府県は物件マスタの「顧客地域」項目に加え、空白の場合は「住所」から自動抽出して補完するため、高い精度で絞り込み可能です。
  - 市区町村は物件マスタの住所情報から自動抽出され、政令指定都市では「福岡市（全区）」単位と「福岡市博多区」などの行政区単位の両方で絞り込みが可能です。
- **リアルタイムキーワード検索**:
  - 入力ボックスに文字を入力すると、物件名および物件コードを対象に即座に対象物件が絞り込まれます。
- **一括選択と状態の永続化（localStorage連携）**:
  - 「表示中を全選択」「選択解除」ボタンにより、絞り込んだ物件を一括で選択・解除できます。
  - 選択した物件のチェック状態やウィンドウの最大化設定はブラウザ（localStorage）に自動保存され、次回起動時も前回の選択状態がそのまま復元されます。
- **豊富な並び順切り替え**:
  - 「物件コード順」「平均売上(ALL) 高い順」「1車室当たり(ALL) 高い順」「1台当たり単価(月極抜) 高い順」「平均出庫台数 多い順」（アラート・比較モード時は当月売上・差額増額・差額ワースト・減少率ワースト等、目標達成率モード時は年間達成率・累計達成率・実績累計・年間目標・差額および任意の列クリック）にワンクリックで並べ替え可能です。

### 3. 操作性と表示の最適化
- **絞り込みパネルの折りたたみ（◀ 絞り込みを隠す / ▶ 絞り込みを表示）**:
  - ツールバー左上のボタンをクリックすることで、左側の絞り込み枠（380px幅）を一時的に非表示にし、右側の数値一覧・ランキング表示領域を画面横幅いっぱいに広げることができます。
- **数字・文字サイズの拡大表示（🔍 数字拡大）**:
  - ツールバー右上の「🔍 数字拡大」ボタンをクリックすることで、ランキングカードや比較表の数値・文字サイズを大きく太く切り替えられます。会議投影やじっくり数値を確認したい場合に最適です。
- **ウィンドウ最大化 / サイズ復元**:
  - ヘッダー右上の「□」ボタンをクリック、またはヘッダータイトルバーをダブルクリックすることで、即座にブラウザ全画面表示に切り替えられます。元のサイズへの復元もワンクリックです。
- **見やすいフォント・サイズ設計**:
  - 文字や数値を大きく見やすいフォントサイズ（14〜16px、拡大時は16〜19px）に最適化し、長時間の分析作業でもストレスのない視認性を実現しています。
- **統一されたボタンスタイル**:
  - レコード一覧画面に追加される呼び出しボタンは、他の業務プラグイン（推移表出力、Tableau帳票等）と完全に統一されたデザイン（青色背景 `#3498db` / 白文字 / 角丸 / シャドウ）を採用しています。
  - 「アプリ内ボタン配列プラグイン」にも対応しており、ボタンID（`propertySalesSummaryButton`）を指定することで自由に配置順をコントロールできます。

### 4. 柔軟なプラグイン設定画面（アプリ・フィールド自動推定プルダウン＆合算項目チェック設定）
- **アプリ・フィールドのプルダウン選択と自動マッピング（v1.6.0 改修）**:
  - 連携アプリ（物件マスタアプリ・売上指標マスタアプリ）は kintone 内のアプリ一覧（`GET /k/v1/apps`）からプルダウンで選択できます。
  - アプリを選択すると対象フィールド一覧（`GET /k/v1/app/form/fields`）を取得し、**保存済み設定値 → 既定フィールドコード → フィールド名（ラベル）推定**の順で自動選択されます。相違がある場合のみ手動でプルダウン変更可能です。
- **元項目からの直接足し算モード（推奨）と計算フィールド参照モード**:
  - kintone上の計算フィールドの式を変更した際、過去レコードが未再計算のまま残ってしまっても影響を受けないよう、**元の各金額フィールド（時間貸し・サービス券・電子マネー・クレカ・ICカード・自転車・プリペイド・その他・月極）をプラグイン側で直接足し算して算出する機能**を搭載しています。
  - プラグイン設定画面にアプリ内の数値項目一覧がチェックボックスで表示され、「①【月極抜】に合算する項目」と「②【合計ALL】にのみ追加合算する項目（月極等）」を自由に選択できます。
  - 将来新しい決済手段や売上の項目がkintoneに追加されても、プログラム改修なしで設定画面からチェックを入れるだけで即座に過去データを含めて集計へ反映されます。
- **売上目標（売上指標マスタ）連携設定（セクション4・任意設定）**:
  - **売上指標マスタアプリ**: プルダウンで選択（未選択でも保存可能。未設定時は従来機能のみ動作）。
  - **指標マスタのフィールド**: 年度（既定 `数値_年度`）、物件コード（既定 `数値_物件コード`）、売上目標(ALL)・年額（既定 `数値_売上目標_ALL`）、月別目標（既定 `数値_月別目標`）、最終月目標（既定 `数値_最終月目標`）。
  - **年度開始月**: 1〜12月（既定 `4` 月）から選択可能。
- **集計月数の動的設定**:
  - 直近推移の集計対象とする月数（デフォルト: 3か月、1〜12か月の範囲で設定可能）を自由に指定できます。

## 各指標の計算仕様

| 指標 | 計算ロジック | 補足 |
| :--- | :--- | :--- |
| **売上金額(ALL)** | 月ごとの合算値（元項目直接足し算 または `計算_ALL`） | 時間貸し・月極等を含む総売上 |
| **売上金額(月極抜)** | 月ごとの合算値（元項目直接足し算 または `計算_月極抜`） | 時間貸し・サービス券等の売上 |
| **出庫台数** | 月ごとの `数値_出庫台数` の合計 | 月間の総出庫台数 |
| **1車室当たり(ALL)** | `売上金額(ALL) ÷ 車室数` | 物件マスタの `数値_車室数` を使用 |
| **1車室当たり(月極抜)** | `売上金額(月極抜) ÷ 車室数` | 物件マスタの `数値_車室数` を使用 |
| **1台当たり単価(ALL)** | `売上金額(ALL) ÷ 当月出庫台数` | 出庫台数が入力されている月のみ算出 |
| **1台当たり単価(月極抜)** | `売上金額(月極抜) ÷ 当月出庫台数` | 出庫台数が入力されている月のみ算出 |
| **3か月平均** | 売上・台数は「実績のある月」の平均。<br>単価は出庫台数のある月の売上合計 ÷ 台数合計。 | 車室数未登録・出庫台数未入力の月は「－」表示 |
| **アラート比較（差額・増減率）** | `当月実績 - 過去2か月平均` / `差額 ÷ 過去2か月平均 × 100` | 過去2か月（前々月・前月）のうち売上>0の月を平均算出。減少率ワーストは過去平均5万円以上・当月売上>0の物件が対象。 |
| **年間目標 / 月別目標** | 年間目標＝`数値_売上目標_ALL`<br>月別目標＝`数値_4月目標`〜`数値_3月目標`（12フィールド）を優先使用（未設定時は1〜11か月目＝`数値_月別目標`、12か月目＝`数値_最終月目標`） | カーソルAPI（`/k/v1/records/cursor`）で対象年度の目標・売上実績を全件取得し物件コードで結合 |
| **年間達成率 / 残り必要額** | `当年度実績累計 ÷ 年間目標 × 100`<br>`MAX(年間目標 - 当年度実績累計, 0)` | 目標未登録（または0）の物件は「目標なし」、達成率は「－」表示 |
| **経過月時点の累計目標・進捗率** | 期首〜当年度で売上実績が存在する最新月までの月別目標合計 と `実績累計 ÷ 累計目標 × 100` | 差額 ＝ `実績累計 - 累計目標` |

## 使用方法

### 1. 準備（プラグインの導入と設定）
1. kintoneシステム管理の「プラグイン」画面で、`parking_sales_quickview_v1.7.3.zip` を読み込みます。
2. 売上レコードアプリ（ID: 155）の設定画面を開き、「プラグイン」から本プラグインを追加します。
3. プラグインの設定画面を開き、物件マスタアプリ（ID: 148）および必要に応じた売上指標マスタアプリを選択し、各フィールドマッピングを確認して「保存」をクリックします（アプリ選択時にフィールドは自動設定されます）。
4. アプリの設定画面で「アプリを更新」を実行します。
5. （任意）ボタンの配置順序を変更したい場合は、「アプリ内ボタン配列プラグイン」の設定画面でボタンID `propertySalesSummaryButton` を追加し、表示順を調整してください。

### 2. 閲覧・分析の操作（アプリトップ画面）
1. レコード一覧画面のヘッダーメニューにある「📊 駐車場売上簡易閲覧」ボタンをクリックします。
2. ポップアップ画面が表示され、当年度の期首〜最新の締まった月（例: 11月実行時は4月〜10月）の売上データが読み込まれます。初期画面として「🏆 売上アラート・比較」ビューが開きます。
3. **絞り込み（都道府県・市区町村・部署・担当者）**:
   - 左側の絞り込みパネルを使って対象を絞り込むと、選択条件に合致する物件の中での **TOP5/10（売上実績・好調・差額ワースト・減少率ワースト）** と **詳細比較推移一覧表** が即座に再計算されて表示されます。
   - 「📥 CSV出力」ボタンをクリックすると、現在の絞り込み結果の詳細推移表をExcel対応CSVとしてダウンロードできます。
4. **物件別推移・地域別平均・目標達成率の確認**:
   - 上部の「📋 物件別推移」タブへ切り替えると、左ペインでチェックを入れた物件の詳細指標（1車室当たり、1台当たり単価等）を確認できます。
   - 「🗾 地域別平均」タブでは、集計単位（都道府県／市区町村／管理部署／当社担当者）ごとのグループ平均を比較できます。
   - 「🎯 目標達成率」タブ（売上指標マスタ設定時）では、対象年度を選択して年間目標・実績累計・達成率・経過月進捗率、部署別・担当者別集計、および12か月推移付きの物件別明細を確認・CSV/Excel出力できます。
5. **見やすさ・画面サイズの調整**:
   - **「◀ 絞り込みを隠す」**: 左側の絞り込み枠を閉じて、数値やランキングを横幅いっぱいに広く表示します。
   - **「🔍 数字拡大」**: カードや表の文字・数値サイズを大きく太く切り替えます。
   - **右上の「□」ボタン**: ウィンドウ全体をブラウザ全画面に最大化します。
