# 駐車場売上簡易閲覧プラグイン 仕様書

## 概要
kintoneアプリ（売上レコードアプリ・アプリID: 155）のトップ画面（レコード一覧画面）に「📊 駐車場売上簡易閲覧」ボタンを追加し、物件ごとの直近3か月の売上実績、1車室当たり売上、1台当たり単価などをポップアップ画面上で直感的に閲覧・比較分析できるプラグインです。
マスタアプリ（駐車場情報・アプリID: 148）と連携し、地域・市区町村・部署・担当者などでの柔軟な絞り込みや複数物件の選択比較、さらにエリアごとの平均値比較をワンクリックで素早く行える環境を提供し、日々の売上把握と迅速な意思決定を強力にサポートします。

## 主な機能

### 1. 直感的な分析UI（売上アラート・物件別推移・地域別平均の3大ビュー）
- **🏆 売上アラート・推移比較モード（新設メインビュー）**:
  - 前月実績 vs 過去2か月平均の比較分析を行い、**「売上実績 TOP 5(10)」「好調物件 TOP 5(10)」「差額ワースト 5(10)」「急減ワースト 5(10)」** をメールと同様の色分けカード形式でリアルタイム表示します。
  - 左ペインの4大フィルター（都道府県・市区町村・部署・担当者）を変更すると、**その絞り込んだ条件の中での好調・不振ランキングと詳細推移表が瞬時に再計算**されます。
  - 下部には、全物件の詳細推移テーブル（前々月、前月、平均、当月、差額、増減率）を表示し、任意の列でソート可能。
  - **📥 CSV出力 / 📊 Excel出力ボタン**: 画面に表示されている絞り込み後のデータ一式をワンクリックでダウンロード可能です。特にExcel出力（`.xlsx`）では以下の**全7シート構成の総合分析レポート**（色分け・数値書式・太枠境界線・ウィンドウ枠固定付き）を1回のクリックで生成します：
    1. `ランキングサマリー`（総計＋TOP5/10・好調・差額ワースト・減少率ワースト）
    2. `詳細比較推移一覧`（合計行＋全件の前々月・前月・平均・当月・差額・増減率）
    3. `物件別推移`（合計＋各物件の全7指標・過去Nか月推移・最大青/最小赤）
    4. `都道府県別平均`（全体平均＋都道府県別の全7指標平均）
    5. `市区町村別平均`（全体平均＋市区町村別の全7指標平均）
    6. `管理部署別平均`（全体平均＋管理部署別の全7指標平均）
    7. `当社担当者別平均`（全体平均＋担当者別の全7指標平均）
- **物件別表示モード**:
  - 選択した物件ごとに、「売上金額(ALL)」「売上金額(月極抜)」「出庫台数」「1車室当たり(ALL)」「1車室当たり(月極抜)」「1台当たり単価(ALL)」「1台当たり単価(月極抜)」の全7指標を、過去3か月推移（月別）および3か月平均で一覧表示します。
  - 複数物件（2件以上）を選択した場合は、表の最上部に「選択物件 合計」行が自動挿入され、選択対象全体の合算実績や車室当たり数値を一目で確認できます。
- **地域別平均モード（タブ切り替え）**:
  - 画面上部のタブをクリックするだけで「地域別平均」ビューへ切り替えられます。
  - 集計単位は「地域」「市区町村」「管理部署」「当社担当者」の4つから自由に選択でき、選択した物件の各指標をグループごとに単純平均（各物件の数値をそのまま平均）して比較できます。
  - 最上部には「選択物件 全体平均」が表示され、全体平均と各グループの数値を容易に対比可能です。
- **最大値（青）・最小値（赤）の自動カラーリング**:
  - 過去3か月の推移の中で、月ごとの最高実績を「青文字（太字）」、最低実績を「赤文字（太字）」で自動強調表示し、好不調の傾向を瞬時に把握できます。
- **視認性を高めた境界線レイアウト**:
  - 物件と物件の境目に太い黒境界線（3px）を配置し、行数の多い帳票でも物件の切り替わりが明確で直感的に読み取れます。

### 2. 柔軟な絞り込み・複数選択・検索機能
- **連動マルチフィルター（都道府県・市区町村・管理部署・当社担当者）**:
  - 「都道府県（地域）」「市区町村」「管理部署」「当社担当者」の各ドロップダウンを搭載。他の条件で絞り込んだ結果に応じて選択肢と件数がリアルタイムに連動します。
  - 都道府県は物件マスタの「顧客地域」項目に加え、空白の場合は「住所」から自動抽出して補完するため、高い精度で絞り込み可能です。
  - 市区町村は物件マスタの住所情報から自動抽出され、政令指定都市では「福岡市（全区）」単位と「福岡市博多区」などの行政区単位の両方で絞り込みが可能です。
- **リアルタイムキーワード検索**:
  - 入力ボックスに文字を入力すると、物件名および物件コードを対象に即座に対象物件が絞り込まれます。
- **一括選択と状態の永続化（localStorage連携）**:
  - 「表示中を全選択」「選択解除」ボタンにより、絞り込んだ物件を一括で選択・解除できます。
  - 選択した物件のチェック状態やウィンドウの最大化設定はブラウザ（localStorage）に自動保存され、次回起動時も前回の選択状態がそのまま復元されます。
- **豊富な並び順切り替え**:
  - 「物件コード順」「平均売上(ALL) 高い順」「1車室当たり(ALL) 高い順」「1台当たり単価(月極抜) 高い順」「平均出庫台数 多い順」（アラート・比較モード時は当月売上・差額増額・差額ワースト・減少率ワースト等）にワンクリックで並べ替え可能です。

### 3. 操作性と表示の最適化
- **絞り込みパネルの折りたたみ（◀ 絞り込みを隠す / ▶ 絞り込みを表示）**:
  - ツールバー左上のボタンをクリックすることで、左側の絞り込み枠（380px幅）を一時的に非表示にし、右側の数値一覧・ランキング表示領域を画面横幅いっぱいに広げることができます。
- **数字・文字サイズの拡大表示（🔍 数字拡大）**:
  - ツールバー右上の「🔍 数字拡大」ボタンをクリックすることで、ランキングカードや比較表の数値・文字サイズを大きく太く切り替えられます。会議投影やじっくり数値を確認したい場合に最適です。
- **ウィンドウ最大化 / サイズ復元**:
  - ヘッダー右上の「□」ボタンをクリック、またはヘッダータイトルバーをダブルクリックすることで、即座にブラウザ全画面表示に切り替えられます。元のサイズへの復元もワンクリックです。
- **見やすいフォント・サイズ設計**:
  - 文字や数値を大きく見やすいフォントサイズ（14〜16px、拡大時は16〜19px）に最適化し、長時間の分析作業でもストレスのない視認性を実現しています。
- **統一されたボタンスタイル**:
  - レコード一覧画面に追加される呼び出しボタンは、他の業務プラグイン（推移表出力、Tableau帳票等）と完全に統一されたデザイン（青色背景 `#3498db` / 白文字 / 角丸 / シャドウ）を採用しています。
  - 「アプリ内ボタン配列プラグイン」にも対応しており、ボタンID（`propertySalesSummaryButton`）を指定することで自由に配置順をコントロールできます。

### 4. 柔軟なプラグイン設定画面（合算項目の動的チェック設定）
- **元項目からの直接足し算モード（推奨）と計算フィールド参照モード**:
  - kintone上の計算フィールドの式を変更した際、過去レコードが未再計算のまま残ってしまっても影響を受けないよう、**元の各金額フィールド（時間貸し・サービス券・電子マネー・クレカ・ICカード・自転車・プリペイド・その他・月極）をプラグイン側で直接足し算して算出する機能**を搭載しています。
  - プラグイン設定画面にアプリ内の数値項目一覧がチェックボックスで表示され、「①【月極抜】に合算する項目」と「②【合計ALL】にのみ追加合算する項目（月極等）」を自由に選択できます。
  - 将来新しい決済手段や売上の項目がkintoneに追加されても、プログラム改修なしで設定画面からチェックを入れるだけで即座に過去データを含めて集計へ反映されます。
- **マスタアプリ・売上アプリのフィールドマッピング**:
  - 物件マスタアプリ（ID: 148）および売上レコードアプリ（ID: 155）の各フィールドを設定画面から柔軟にマッピング可能です。
- **集計月数の動的設定**:
  - 集計対象とする月数（デフォルト: 3か月、1〜12か月の範囲で設定可能）を自由に指定できます。

## 各指標の計算仕様

| 指標 | 計算ロジック | 補足 |
| :--- | :--- | :--- |
| **売上金額(ALL)** | 月ごとの `計算_ALL` の合計 | 時間貸し・月極等を含む総売上 |
| **売上金額(月極抜)** | 月ごとの `計算_月極抜` の合計 | 時間貸し・サービス券等の売上 |
| **出庫台数** | 月ごとの `数値_出庫台数` の合計 | 月間の総出庫台数 |
| **1車室当たり(ALL)** | `売上金額(ALL) ÷ 車室数` | 物件マスタの `数値_車室数` を使用 |
| **1車室当たり(月極抜)** | `売上金額(月極抜) ÷ 車室数` | 物件マスタの `数値_車室数` を使用 |
| **1台当たり単価(ALL)** | `売上金額(ALL) ÷ 当月出庫台数` | 出庫台数が入力されている月のみ算出 |
| **1台当たり単価(月極抜)** | `売上金額(月極抜) ÷ 当月出庫台数` | 出庫台数が入力されている月のみ算出 |
| **3か月平均** | 売上・台数は「実績のある月」の平均。<br>単価は出庫台数のある月の売上合計 ÷ 台数合計。 | 車室数未登録・出庫台数未入力の月は「－」表示 |
| **アラート比較（差額・増減率）** | `当月実績 - 過去2か月平均` / `差額 ÷ 過去2か月平均 × 100` | 過去2か月（前々月・前月）のうち売上>0の月を平均算出。減少率ワーストは過去平均5万円以上・当月売上>0の物件が対象。 |

## 使用方法

### 1. 準備（プラグインの導入と設定）
1. kintoneシステム管理の「プラグイン」画面で、`parking_sales_quickview_v1.5.0.zip` を読み込みます。
2. 売上レコードアプリ（ID: 155）の設定画面を開き、「プラグイン」から本プラグインを追加します。
3. プラグインの設定画面を開き、各フィールドマッピングを確認して「保存」をクリックします（標準運用の場合は初期設定のままで問題ありません）。
4. アプリの設定画面で「アプリを更新」を実行します。
5. （任意）ボタンの配置順序を変更したい場合は、「アプリ内ボタン配列プラグイン」の設定画面でボタンID `propertySalesSummaryButton` を追加し、表示順を調整してください。

### 2. 閲覧・分析の操作（アプリトップ画面）
1. レコード一覧画面のヘッダーメニューにある「📊 駐車場売上簡易閲覧」ボタンをクリックします。
2. ポップアップ画面が表示され、直近3か月（例: 11月実行時は8月〜10月）の売上データが読み込まれます。初期画面として「🏆 売上アラート・比較」ビューが開きます。
3. **絞り込み（都道府県・市区町村・部署・担当者）**:
   - 左側の絞り込みパネルを使って対象を絞り込むと、選択条件に合致する物件の中での **TOP5/10（売上実績・好調・差額ワースト・減少率ワースト）** と **詳細比較推移一覧表** が即座に再計算されて表示されます。
   - 「📥 CSV出力」ボタンをクリックすると、現在の絞り込み結果の詳細推移表をExcel対応CSVとしてダウンロードできます。
4. **物件別推移・地域別平均の確認**:
   - 上部の「📋 物件別推移」タブへ切り替えると、左ペインでチェックを入れた物件の詳細指標（1車室当たり、1台当たり単価等）を確認できます。
   - 「🗾 地域別平均」タブでは、集計単位（都道府県／市区町村／管理部署／当社担当者）ごとのグループ平均を比較できます。
5. **見やすさ・画面サイズの調整**:
   - **「◀ 絞り込みを隠す」**: 左側の絞り込み枠を閉じて、数値やランキングを横幅いっぱいに広く表示します。
   - **「🔍 数字拡大」**: カードや表の文字・数値サイズを大きく太く切り替えます。
   - **右上の「□」ボタン**: ウィンドウ全体をブラウザ全画面に最大化します。
