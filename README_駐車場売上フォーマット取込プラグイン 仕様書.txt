# 駐車場売上フォーマット取込プラグイン 仕様書

## 概要

各種駐車場管理システムから出力されるエクセル（.xlsx）やCSV形式の売上データを、kintoneアプリへ簡単に一括登録するためのプラグインです。複雑なデータのプレビュー確認、マスタ情報の自動補完、およびLINE WORKSへの実行結果通知を備えています。

## 主な機能

### 1. 柔軟なデータ取込
- **複数ファイル形式対応**: エクセルファイル（.xlsx）およびCSV形式に対応。
- **プレビュー機能**: 取り込みを実行する前に、画面上で取込内容を最終確認できます。
- **マルチカラム対応**: 1つのフィールドに対して複数の列（例：I列とJ列）を紐付け、どちらかに値がある方を優先して取り込むことが可能です。

### 2. 高度なデータ補完（マスター連携）
- **マスタ自動補完**: 物件コードをキーとして、別のアプリアプリ（物件マスタ等）から物件名や住所などの関連情報を自動的に取得・充填します。
- **2パス補完ロジック**: 
  1. まず指定されたエクセル列を全て確認。
  2. それでも空の場合にのみ、マスタ情報やあらかじめ設定した「固定値」で補完を行います。
- **フォールバック**: マスタにもデータがない場合に備え、あらかじめ「固定値」を設定しておくことが可能です。

### 3. 日付補完機能
- **カレンダー選択**: 出力CSVに日付データが含まれないフォーマットでも、データの取込画面（プレビュー前）でカレンダーUIから対象の日付を選択し、全行へ一括登録することが可能です。
- **プロファイル別設定**: プラグイン設定画面から、プロファイルごとに日付補完機能のON/OFFおよび、補完先の kintone 日付フィールドを指定できます。

### 4. 安心・安全な登録制御
- **リアルタイム検証**: 取込時に形式不正、必須項目の欠損、マスタ情報の不一致を自動検出。
- **登録ロック**: エラーがある場合は取込ボタンが非活性化され、不正なデータの登録を未然に防ぎます。
- **詳細なエラー診断**: `CB_VA01`等のエラー発生時に、どのフィールドの何が問題か（「必須です」等）を具体的にダイアログとコンソールへ表示します。

### 4. 実行結果通知 (LINE WORKS)
- **成功通知**: 取込件数や売上合計金額をLINE WORKSへ即座に通知。
- **失敗通知**: 万が一の失敗時、エラー理由と該当の行番号を通知することで、迅速なリカバリを支援します。

## プラグイン設定項目

### 基本設定
- **プロファイル管理**: 取引先やシステムごとに異なる取込ルール（開始行、列番号等）を複数保存し、切り替えて使用できます。プロファイルの複製も可能です。
- **取込開始行**: ヘッダーなどを除いた、実際のデータが開始される行番号を指定。
- **エラー判定列**: その行にデータが存在するかどうかを判断するための基準列。

### マスターアプリ連携設定
- **連携先アプリ**: 補完情報を取得したいマスタアプリ（物件マスタ等）を選択。
- **リンクキー**: 取込データとマスタデータの照合に使用するフィールド。

### フィールドマッピング
- **取込先フィールド**: データを登録するkintoneのフィールド。
- **Excel列**: 取込元の列文字（A, B, C...）。複数列指定（I,Jなど）による自動優先選択が可能です。
- **マスタ引当フィールド (任意)**: 取込先フィールドにマスタの情報を入れたい場合、対象のマスタフィールドを直接指定します。（例：ルックアップ_物件名 に対して 物件名 を引当）
- **固定値**: エクセル列もマスタも空の場合にセットする既定値。
- **操作**: 「↑」「↓」ボタンで項目の順番を並び替え、また「削除」ボタンで項目のマッピングを解除できます。
