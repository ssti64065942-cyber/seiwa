# 関連レコード合計表示プラグイン

## 概要

kintoneの関連レコード一覧に表示されている数値フィールドの合計値を自動的に表示するプラグインです。

### 主な機能
- 複数の関連レコード一覧に対応
- 合計する項目を柔軟に選択可能
- 自動計算・自動表示
- レコード詳細画面で即座に確認可能

## インストール方法

### 1. プラグインのパッケージング

PowerShellで以下のコマンドを実行：
```powershell
# 初回作成時
npx @kintone/plugin-packer "プラグインフォルダのパス"

# 更新時（秘密鍵を使用）
npx @kintone/plugin-packer --ppk "秘密鍵.ppk" "プラグインフォルダのパス"
```

### 2. プラグインのインストール
1. kintoneのシステム管理画面を開く
2. 「プラグイン」をクリック
3. 「読み込む」から生成された `plugin.zip` をアップロード

### 3. アプリへの追加
1. 対象のアプリの設定画面を開く
2. 「設定」→「プラグイン」
3. インストールしたプラグインを追加

## プラグイン設定

### 設定画面の開き方
1. アプリの設定画面を開く
2. 「プラグイン」タブ
3. 「関連レコード合計表示プラグイン」の歯車アイコンをクリック

### 設定項目

#### 関連レコード一覧の設定

複数の関連レコード一覧に対して、それぞれ合計する項目を設定できます。

| 項目 | 必須 | 説明 |
|------|------|------|
| **関連レコード一覧フィールド** | ○ | 合計を表示したい関連レコード一覧を選択 |
| **合計する項目** | ○ | チェックを入れた項目の合計が表示される |

#### 操作
- **＋ 関連レコード一覧を追加**: 新しい設定ブロックを追加
- **削除**: 該当する設定ブロックを削除
- **保存**: 設定を保存してアプリを更新

### 設定例
```
【設定1】
関連レコード一覧: 関連レコード一覧_当月
合計する項目:
  ☑ 時間貸し
  ☑ サービス券
  ☑ プリペイド
  ☑ その他

【設定2】
関連レコード一覧: 関連レコード一覧_前月
合計する項目:
  ☑ 時間貸し
  ☑ サービス券
```

## 使用方法

### 1. 初期設定
1. プラグインをアプリに追加
2. プラグイン設定画面で関連レコード一覧と合計項目を設定
3. 設定を保存
4. アプリを更新

### 2. 合計の確認
1. レコード詳細画面を開く
2. 関連レコード一覧の最下部に**合計行**が自動表示される

### 表示例
```
┌─────────┬──────────┬────────────┬──────────┬──────────┐
│ 伝票番号 │ 売上日    │ 時間貸し    │ サービス券 │ その他    │
├─────────┼──────────┼────────────┼──────────┼──────────┤
│ S0099   │2018-12-15│ 22,700 円  │ 0 円     │ 0 円     │
│ S0001   │2019-01-15│ 1,620 円   │ 0 円     │ 0 円     │
├─────────┴──────────┼────────────┼──────────┼──────────┤
│              合計: │ 24,320 円  │ 0 円     │ 0 円     │
└────────────────────┴────────────┴──────────┴──────────┘
```

## 技術仕様

### 対応フィールドタイプ
- **関連レコード一覧**: `REFERENCE_TABLE`
- **合計対象**: 数値フィールド (`NUMBER`) および 計算フィールド (`CALC`)

### 使用API

| API | 用途 |
|-----|------|
| `kintone.plugin.app.getConfig()` | プラグイン設定取得 |
| `kintone.plugin.app.setConfig()` | プラグイン設定保存 |
| `kintone.api()` | フィールド情報取得 |
| `kintone.events.on()` | イベント登録 |

### ブラウザ互換性
- Chrome（最新版）
- Firefox（最新版）
- Safari（最新版）
- Edge（最新版）

## トラブルシューティング

### Q1: 合計が表示されない
**A**: 以下を確認してください：
- プラグイン設定で関連レコード一覧と合計項目が正しく設定されているか
- アプリが更新されているか
- ブラウザのキャッシュをクリアして再読み込み

### Q2: 設定画面で関連レコード一覧が選択できない
**A**: 以下を確認してください：
- アプリに関連レコード一覧フィールドが存在するか
- フィールドタイプが `REFERENCE_TABLE` であるか

### Q3: 関連先アプリの項目が表示されない
**A**: 以下を確認してください：
- 関連先アプリに数値フィールドが存在するか
- 関連先アプリの閲覧権限があるか

### Q4: 設定していない関連レコード一覧にも合計が表示される
**A**: 古いバージョンをお使いの場合、最新版に更新してください。

### デバッグ方法
1. ブラウザの開発者ツールを開く（F12キー）
2. 「Console」タブを選択
3. エラーメッセージやログを確認

## 制限事項

### 機能制限
- 関連レコード一覧フィールド (`REFERENCE_TABLE`) のみ対応
- 合計対象は数値・計算フィールドのみ
- レコード詳細画面でのみ表示（編集画面・作成画面では非対応）

### データ量制限
- 関連レコード一覧に表示されるレコード数に依存
- kintone APIの制限に準拠

---

## セキュリティ

### アクセス制御
- プラグインはユーザーの権限で動作
- アプリの閲覧権限がないユーザーはデータ取得不可

### データ処理
- すべての処理はクライアント（ブラウザ）側で実行
- データは外部サーバーに送信されない
