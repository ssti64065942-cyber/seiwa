# 物件レコード確認（マトリックス表示）プラグイン 仕様書

## 1. 概要

### 1.1 プラグイン名
**物件レコード確認（マトリックス表示） (Property Record Confirmation - Matrix Display)**

### 1.2 目的
kintoneのレコード一覧画面において、特定の物件（商品）および対象月のレコードを抽出・集計し、日次および科目別の実績をマトリックス形式（縦軸：日付、横軸：科目名）で視覚的に確認・入力・編集するためのプラグインです。さらに月間トータルの実績を一覧表示する機能も備えています。

### 1.3 主な機能
- **マトリックス表示**: 縦軸に1日〜末日、横軸に設定された科目名を配置した一覧を表示。
- **動的な集計項目設定**: 管理したい「科目名」と「金額」のペアを設定可能。「付加ステータス」による科目の自動分割（例: "売上(A)"/"売上(B)"）もサポート。
- **計算科目の設定**: 動的に取得した科目を四則演算し、新たな計算列として表示可能。
- **月間設定の複数セット・即時切替**: 業務ごとに月間合計一覧の表示列パターンを複数保存でき、一覧画面上部のプルダウンから瞬時に切り替え可能。
- **2画面同時比較**: 月間合計一覧の物件行から「日次表示」ボタンで、小窓として日次マトリックスを展開し比較可能。
- **表示並び順のカスタマイズ**: 日次マトリックスは表示ルールの選択、月間合計一覧はフリー設定（科目・計算式・合計などの要素を完全に自由に個別配置）が可能。
- **イン・ビュー・ナビゲーション**: マトリックス画面を開いたまま、対象月や物件をプルダウンで瞬時に切り替え可能。
- **レコード作成・編集連携**: 
    - 既存レコードがある日は「✎ (編集)」ボタンから詳細画面へ。
    - レコードがない日は「+ (新規作成)」ボタンから、日付と物件が自動入力された状態で作成画面へ。
- **物件検索機能**: モーダル内での部分一致検索（名称・コード）により、大量の物件から目的のものを素早く選択。

## 3. プラグイン設定

### 3.1 基本フィールド設定
| 項目 | 型 | 説明 |
|------|-----|------|
| 日付フィールド | 日付 | 集計の基準となる「日付」が入っているフィールドを選択 |
| 物件名フィールド | 文字列(1行) / ドロップダウン | 物件名（商品名）を特定するためのフィールドを選択 |
| 物件コードフィールド | 文字列(1行) / 数値 / ルックアップ | 物件コード（店舗番号等）を特定するためのフィールドを選択 |

### 3.2 マトリックス表示用 設定
| 項目 | 説明 |
|------|------|
| 合計列の表示位置 | 日次マトリックスにおける「動的科目列」「合計（税込）」「合計（税抜）」の表示順序を指定します。 |
| 集計項目設定 | 科目名フィールド・付加ステータス・金額フィールドを紐付けます。「合計対象」にチェックを入れると日次合計に加算されます。 |

### 3.3 月間合計一覧用 設定（設定セット）
| 項目 | 説明 |
|------|------|
| セット名 | 表示切り替えに用いる設定パターンの名称を付けます。（複数登録可能） |
| データ抽出設定 | マトリックスと同様に「科目」「（付加ステータス）」「金額」を紐付け、対象とするデータを定義します。 |
| 表示列の定義リスト | 画面の左から表示する列を上から順に個別定義。「指定の科目」「計算科目」「合計」「税抜合計」「その他すべて」を思い通りに並び替えできます。 |

### 3.4 その他設定
| 項目 | 説明 |
|------|------|
| 税率設定 | 金額を税抜表示するための税率（%）を指定します。（計算結果の端数は切り捨て） |

## 4. 使用方法

### 4.1 初期設定
1. プラグインをアプリにインストール・有効化します。
2. 設定画面で「日付」「物件名」「物件コード」の各フィールドを指定します。
3. マトリックス表示用の設定および、月間合計一覧で用いる「設定セット」を作成し列定義を構築します。
4. 任意で税率を設定します。
5. [保存] をクリックし、アプリの設定を更新（反映）します。

### 4.2 マトリックスの表示と操作
1. レコード一覧画面のヘッダーにある **[物件レコード確認]** ボタンをクリックします。
2. 表示されたモーダルで「対象月」などを選択し、「日次表示」か「月間合計一覧」をクリックします。
3. 画面が表示されます：
    - **月間合計画面の特有操作**:
        - 上部の `表示設定セットの切り替え` プルダウンから瞬時に表示パターンを切り替えられます。
        - 物件行の `日次表示` ボタンをクリックして、日次マトリックスの小窓を展開し同時比較できます。
    - **マトリックス画面の特有操作**: 
        - 上部のプルダウンから月や物件を直接切り替えられます。
        - `✎`: 既存レコードの詳細画面を別タブで開きます。
        - `+`: 新規作成画面を別タブで開き、日付と物件を自動セットします。
    - **閉じる**: 右上の [閉じる] ボタンで一覧画面に戻ります。

## 5. 技術仕様・制限事項

### 5.1 データ取得仕様
- 指定した物件および期間（1日〜月末）の全レコードを自動ループで制限なく取得・合算します。
- カスタム設定した計算式の処理はJavaScriptの `new Function` を用いた安全なローカル展開で稼働します。

### 5.2 制限事項
- **フィールドタイプ**: 金額フィールドは数値または計算フィールドのみ対応しています。
- **データ量**: リクエスト制限（10,000件オフセット制限）を考慮したループ取得を行っていますが、極端に大量のデータがある場合は表示に時間がかかる可能性があります。
