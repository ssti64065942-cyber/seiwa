# 物件レコード確認（マトリックス表示）プラグイン 仕様書
## 1. 概要
### 1.1 プラグイン名
**物件レコード確認（マトリックス表示） (Property Record Confirmation - Matrix Display)**
### 1.2 目的
kintoneのレコード一覧画面において、特定の物件（商品）および対象月のレコードを抽出・集計し、日次および科目別の実績をマトリックス形式（縦軸：日付、横軸：科目名）で視覚的に確認・入力・編集するためのプラグインです。さらに月間トータルの実績を一覧表示する機能も備えています。
### 1.3 主な機能
- **マトリックス表示**: 縦軸に1日〜末日、横軸に設定された科目名を配置した一覧を表示。
- **動的な集計項目設定**: 管理したい「科目名」と「金額」のペアを設定可能。「付加ステータス」による科目の自動分割（例: "売上(A)"/"売上(B)"）もサポート。
- **計算科目の設定**: 動的に取得した科目を四則演算し、新たな計算列として表示可能。
- **月間設定の複数セット・即時切替**: 業務ごとに月間合計一覧の表示列パターンを複数保存でき、一覧画面上部のプルダウンから瞬時に切り替え可能。
- **2画面同時比較**: 月間合計一覧の物件行から「日次表示」ボタンで、小窓として日次マトリックスを展開し比較可能。
- **表示並び順のカスタマイズ**: 日次マトリックスは表示ルールの選択、月間合計一覧はフリー設定（科目・計算式・合計などの要素を完全に自由に個別配置）が可能。
- **イン・ビュー・ナビゲーション**: マトリックス画面を開いたまま、対象月や物件をプルダウンで瞬時に切り替え可能。
- **レコード作成・編集連携**: 
    - 既存レコードがある日は「✎ (編集)」ボタンから詳細画面へ。
    - レコードがない日は「+ (新規作成)」ボタンから、日付と物件が自動入力された状態で作成画面へ。
- **物件検索機能**: モーダル内での部分一致検索（名称・コード）により、大量の物件から目的のものを素早く選択。

## 3. プラグイン設定
### 3.1 基本フィールド設定
| 項目 | 型 | 説明 |
|------|-----|------|
| 日付フィールド | 日付 | 集計の基準となる「日付」が入っているフィールドを選択 |
| 物件名フィールド | 文字列(1行) / ドロップダウン | 物件名（商品名）を特定するためのフィールドを選択 |
| 物件コードフィールド | 文字列(1行) / 数値 / ルックアップ | 物件コード（店舗番号等）を特定するためのフィールドを選択 |
