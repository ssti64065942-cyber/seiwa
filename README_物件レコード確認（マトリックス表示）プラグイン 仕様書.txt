# 物件レコード確認（マトリックス表示）プラグイン 仕様書

## 1. 概要

### 1.1 プラグイン名
**物件レコード確認（マトリックス表示） (Property Record Confirmation - Matrix Display 1)**

### 1.2 目的
kintoneのレコード一覧画面において、特定の物件（商品）および対象月のレコードを抽出・集計し、日次および科目別の実績をマトリックス形式（縦軸：日付、横軸：科目名）で視覚的に確認・入力・編集するためのプラグインです。

### 1.3 主な機能
- **マトリックス表示**: 縦軸に1日〜末日、横軸に設定された科目名を配置した一覧を表示。
- **動的な集計項目設定**: 管理したい「科目名」と「金額」のペアを複数設定可能。
- **並び順のカスタマイズ**: 設定画面でドラッグ＆ドロップによる項目の表示順序（列の並び）を調整可能。
- **合計・平均の自動算出**: 列ごとの合計・日平均、および特定項目を対象とした「日次合計」を自動計算。
- **イン・ビュー・ナビゲーション**: マトリックス画面を開いたまま、対象月や物件をプルダウンで瞬時に切り替え可能。
- **レコード作成・編集連携**: 
    - 既存レコードがある日は「✎ (編集)」ボタンから詳細画面へ。
    - レコードがない日は「+ (新規作成)」ボタンから、日付と物件が自動入力された状態で作成画面へ。
- **物件検索機能**: モーダル内での部分一致検索（名称・コード）により、大量の物件から目的のものを素早く選択。

## 3. プラグイン設定

### 3.1 基本フィールド設定
| 項目 | 型 | 説明 |
|------|-----|------|
| 日付フィールド | 日付 | 集計の基準となる「日付」が入っているフィールドを選択 |
| 商品名フィールド | 文字列(1行) / ドロップダウン | 物件名（商品名）を特定するためのフィールドを選択 |
| 物件コードフィールド | 文字列(1行) / 数値 / ルックアップ | 物件コード（店舗番号等）を特定するためのフィールドを選択 |

### 3.2 集計項目設定（テーブル形式）
複数の「科目」と「金額」の組み合わせを登録します。

| 項目 | 説明 |
|------|------|
| 並び | ドラッグ（☰）して行を入れ替えると、マトリックス上の左からの表示順に反映されます |
| 科目名フィールド | 「時間貸」「定期」などの科目名が入っているフィールドを選択 |
| 金額フィールド | 集計対象となる金額の数値フィールドを選択 |
| 合計対象 | チェックを入れると、その項目の値がマトリックス右端の「日次合計」に加算されます |

## 4. 使用方法

### 4.1 初期設定
1. プラグインをアプリにインストール・有効化します。
2. 設定画面で「日付」「商品名」「物件コード」の各フィールドを指定します。
3. 集計したい科目の数だけテーブルに行を追加し、フィールドを選択します。
4. [保存] をクリックし、アプリの設定を更新（反映）します。

### 4.2 マトリックスの表示と操作
1. レコード一覧画面のヘッダーにある [物件レコード確認] ボタンをクリックします。
2. 表示されたモーダルで「対象月」を選択し、「物件」を検索・選択して [表示する] をクリックします。
3. マトリックス画面が表示されます：
    - 切り替え: 上部のプルダウンから月や物件を直接切り替えられます。
    - 編集/作成: 左端のボタンをクリック：
        - ✎: 既存レコードの詳細画面を別タブで開きます。
        - +: 新規作成画面を別タブで開き、日付と物件を自動セットします。
    - 閉じる: 右上の [閉じる] ボタンで一覧画面に戻ります。

## 5. 技術仕様・制限事項

### 5.1 データ取得仕様
- 指定した物件および期間（1日〜月末）の全レコードを取得します。
- 同一日に複数レコードがある場合、各項目の数値は合算して表示されます。

### 5.2 制限事項
- フィールドタイプ: 金額フィールドは数値または計算フィールドのみ対応しています。
- データ量: kintone APIの制限を考慮したループ取得を行っていますが、極端に大量のデータがある場合は表示に時間がかかる可能性があります。
