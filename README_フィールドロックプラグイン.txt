フィールドロックプラグイン 仕様書

概要
Kintone アプリの特定フィールドを管理者ユーザーのみが編集できるようにし、非管理者の編集を禁止するクライアント側プラグインです。保存時の検査で非管理者による変更を検知すると保存を中止してエラーを表示します。データ編集の誤操作防止と運用ルールの担保を目的とします。

主な機能

1. フィールドの読み取り専用化
- 指定したフィールドを非管理者から読み取り専用にする
- 管理者ユーザーのみ編集可能
- 非管理者が変更を行って保存しようとした場合はエラーで保存を中止

2. 管理者ユーザー設定
- kintone のユーザー一覧からチェックボックス式で複数ユーザーを指定可能
- 未設定の場合は全ユーザーを非管理者扱い（全員編集不可）

3. 視覚的フィードバック
- ロック対象フィールドのラベルを赤色かつ太字で表示（設定で ON/OFF）
- ラベル下に「(編集できません)」の注釈を赤色で表示するオプション（設定で ON/OFF）

4. 保存時検査
- 非管理者が編集画面でロック対象フィールドの値を変更していないかをチェック
- 変更があれば保存を中止し、対象フィールド名を表示したエラーメッセージを出力

プラグイン設定項目

基本設定
- ロック対象フィールド（必須）
  - 表示形式: チェックボックス（複数選択可）
  - 表示内容: フィールド名、フィールドコード、フィールドタイプ
  - 対応フィールドタイプは後述

- 管理者ユーザー（任意）
  - 表示形式: チェックボックス（複数選択可）
  - 表示内容: ユーザー名、ログインコード、メールアドレス
  - 取得元: kintone のユーザー一覧 API（有効ユーザーのみ）
  - 動作: 選択ユーザーのみロック解除（編集可）。未選択なら全員非管理者（警告表示）

動作設定
- 編集不可フィールドをハイライト表示する
  - チェック ON: ラベルを赤色・太字で表示（デフォルト: ON）
  - チェック OFF: 通常表示

- フィールドに「編集できません」の注釈を表示する
  - チェック ON: ラベル下に「(編集できません)」を赤色で表示（デフォルト: ON）
  - チェック OFF: 注釈なし

対応フィールドタイプ
- 文字列（1行）
- 文字列（複数行）
- リッチテキスト
- 数値
- 計算
- ラジオボタン
- チェックボックス
- ドロップダウン（単一・複数選択）
- 日付 / 時刻 / 日時
- ユーザー選択 / 組織選択 / グループ選択
- リンク

使用方法（導入手順）

1. プラグインを kintone にアップロード
2. 対象アプリにプラグインを追加
3. プラグイン設定画面で以下を設定
   - ロック対象フィールドを選択
   - 管理者ユーザーを選択（任意）
   - ハイライト表示・注釈表示の ON/OFF を確認
   - 設定を保存
4. アプリを更新（公開）して設定を反映

レコード操作フロー（ユーザー操作時）

- レコード作成・編集画面表示時（管理者）
  - ロック対象フィールドは通常通り編集可能
  - ハイライト・注釈は表示されない（設定に依らず管理者は編集可能）

- レコード作成・編集画面表示時（非管理者）
  - ロック対象フィールドを読み取り専用化
    - 入力系フィールドに `readOnly` 属性を付与
    - ドロップダウン等に `disabled` 属性を付与
    - ルックアップ等のボタンを無効化
    - キーボード入力、ペースト、ドロップを無効化
  - 設定に応じてラベルを赤色・太字にし、注釈を表示

- レコード保存時
  - 管理者: 保存を許可
  - 非管理者: ロック対象フィールドの値が変更されているかをチェック
    - 変更なし → 保存を許可
    - 変更あり → 保存中止、エラーメッセージ表示
      - 例: 「以下のフィールドは編集できません（管理者のみ編集可）: フィールド名」

```text

├── manifest.json         # プラグイン定義
├── icon.png              # プラグインアイコン
├── js/
│   ├── desktop.js        # メイン処理（表示・submit ハンドリング）

```

使用 API / SDK
- kintone REST API
  - `/k/v1/app/form/fields` - フォーム設定取得
  - `/v1/users` - ユーザー一覧取得
- kintone JavaScript API
  - `kintone.plugin.app.getConfig()` / `kintone.plugin.app.setConfig()`
  - `kintone.getLoginUser()`
  - `kintone.app.record.getFieldElement()`
  - `kintone.events.on()`（`app.record.create.show`, `app.record.edit.show`, `app.record.create.submit`, `app.record.edit.submit` など）

プラグイン設定データ形式（例）
```javascript
{
  "lockFields": "[\"fieldCode1\",\"fieldCode2\"]", // JSON文字列
  "adminUsers": "user1@example.com\nuser2@example.com", // 改行区切り
  "showHighlight": "true",
  "showNote": "true"
}
```

管理者判定ロジック
- ログインユーザーのいずれかが管理者リストに一致するかを判定:
  1. `loginUser.code`（ログインコード）
  2. `loginUser.email`（メールアドレス）
  3. `loginUser.name`（表示名）
- いずれか一致 → 管理者（編集可）
- 全て不一致 → 非管理者（編集不可）
- 管理者リストが空 → 全ユーザーを非管理者扱い（全員編集不可）

制限事項
- 非対応:
  - テーブル（サブテーブル）内のフィールド
  - 添付ファイルフィールド
  - 関連レコード一覧
- クライアントサイド制御の限界:
  - 開発者ツールや API を使えば回避される可能性あり
  - 高いセキュリティ要件がある場合は kintone のアクセス権限機能と併用を推奨（フィールド編集権限、レコード編集権限、アプリ権限）

対応環境
- kintone（クラウド版）
- モダンブラウザ: Chrome, Firefox, Safari, Edge
- JavaScript 無効環境では動作しない

トラブルシューティング

- プラグインが動作しない
  - ブラウザのコンソール（F12）でエラーを確認
  - アプリが更新されているか確認
  - ブラウザのキャッシュをクリア

- 管理者なのに編集できない
  - `kintone.getLoginUser()` の値をコンソールで確認
  - 設定画面で正しいユーザーが選択されているかを確認
  - ログインコード・メール・名前のいずれかが一致しているかを確認

- ハイライトや注釈が表示されない
  - プラグイン設定の「編集不可フィールドをハイライト表示する」「注釈を表示する」が ON か確認
  - フィールドコードが正しいか確認
  - コンソールログでエラーを確認

ログ出力（コンソール）
- `[field-lock-plugin] script loaded`
- `[field-lock-plugin] LOCK_FIELDS:`
- `[field-lock-plugin] ADMIN_USER_CODES:`
- `[field-lock-plugin] isAdmin:`
- `[field-lock-plugin] show event:`
- `[field-lock-plugin] submit event:`

サポート
エラー発生時はブラウザの開発者ツールでコンソールログを確認し、ログ内容を含めて開発元へ問い合わせてください。
