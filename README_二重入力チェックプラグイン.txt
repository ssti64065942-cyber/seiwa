# 二重入力チェックプラグイン

## 概要
同じ日付・同じ物件での重複入力を防止するためのkintoneプラグインです。
売上科目などの特定フィールドに値が入っている場合のみチェックを実行し、さらに特定の項目については一度登録した値の変更を禁止する（ロック）機能も備えています。
また、**[NEW]** フィールドが空の場合に指定した値を自動入力して保存する「空値補完」機能を追加しました。

## 主な機能
- ✅ **柔軟な重複判定**: 日付と物件名をキーに重複を判定
- ✅ **詳細な発動条件**: 「売上が > 0 の時だけチェック」など、個別の科目・数値・文字列条件でチェックを実行
- ✅ **日付・物件名の組み合わせ重複を常に禁止**: 設定により、科目条件に関わらず基本的なユニークチェックを強制可能
- ✅ **保存時の特例登録**: 特定の条件を満たす場合、自身の重複チェックをバイパスし保存を許可
- ✅ **既存レコードの判定除外**: 特定の条件を満たす既存レコードを重複判定の対象から除外（スルー）する機能
- ✅ **変更禁止（ロック）機能**: 初回登録時の値を固定し、以降の変更を禁止可能
- ✅ **空値補完機能**: 指定した項目が未入力の場合、設定値を自動的に入力して保存
- ✅ **フィールド単位のエラー表示**: 重複箇所を赤字で強調し、原因の既存レコード番号も表示
- ✅ **多彩なフィールド対応**: 数値・計算だけでなく、文字列・ドロップダウン・ラジオボタンにも対応

## インストール方法

### 1. プラグインの準備
`plugin.zip` ファイルがパッケージ済みです。

### 2. kintoneへのアップロード
1. kintone管理画面 → プラグイン
2. 「読み込む」ボタンから `plugin.zip` をアップロード
3. プラグインを有効化

### 3. アプリへの適用
1. 対象アプリの設定画面を開く
2. 「プラグイン」タブ → このプラグインを追加
3. 設定ボタンをクリックして各項目を設定

## 設定方法

### 重複判定キー設定
| 項目 | 説明 | 必須 |
|------|------|:----:|
| 日付フィールド | 重複判定の基準となる日付項目（売上日など） | ⭕ |
| 物件名フィールド | 重複判定の基準となる検索キー項目（物件名、コードなど） | ⭕ |
| 重複登録を常に禁止する | 条件に関わらず同じ日付・物件のレコードがあれば登録をブロックします | - |

### チェック対象科目設定
（＋）ボタンで複数のルールを追加できます：
- **対象フィールド**: チェックのトリガーとなる項目
- **条件・値**: どのような値が入力された時に重複チェックを動かすか（例：`!= 0`）
- **変更禁止**: ONにすると、一度その日付・物件で登録された値は以降変更できなくなります
- **空時に補完**: **[NEW]** フィールドが空で保存された際、上記「値」の内容を自動入力します

## 使い方
1. レコードの追加・編集画面で値を入力します。
2. 保存ボタンをクリックした際、プラグインが背後で値をチェック・補完します。
3. **空値補完**: 「空時に補完」がONの項目が未入力の場合、設定された値が補完されます。
4. **「常に禁止」がONの場合**: 同じ日付・物件のレコードが既に存在すれば即座にエラーとなります。
5. **「常に禁止」がOFFの場合**: 設定した条件を満たす値が入力された際、既存レコードと重複していればエラーとなります。

## 技術仕様

### 対応フィールドタイプ
- **日付キー**: 日付 フィールド
- **物件キー**: 文字列（1行）、数値、ルックアップ、レコード番号、ドロップダウン、ラジオボタン、リンク
- **チェック項目**: 数値、計算、文字列（1行・複数行）、ドロップダウン、ラジオボタン

### 重複判定ロジック
- 保存時に REST API で同一キー（日付・物件名）のレコードを検索。
- 値が空の場合、設定に基づき自動的に補完を実行。
- 「常に重複禁止」設定が有効な場合、レコードの存在自体をチェック。
- 設定条件（Criteria）がある場合、その条件を満たす既存レコードがあるかチェック。
- 編集時は自分自身のレコードIDを考慮（自分自身との重複は無視）。
- 変更禁止項目については、登録済みの値と異なる入力があればブロック。

## トラブルシューティング

### 重複チェックが期待通りに動かない
- **「常に禁止」設定**が意図通りになっているか確認してください。
- 特定の条件（売上が入った時など）のみチェックしたい場合は「常に禁止」をOFFにし、ルールを設定してください。
- フィールドコードの変更があった場合は、プラグイン設定を再保存してください。
