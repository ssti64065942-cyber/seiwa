# 値比較プラグイン

## 概要

自アプリ（現在のアプリ）と別アプリの間で、共通のキー（物件コード等）を基に数値データ（売上、点検結果など）を照合・比較するためのプラグインです。集計期間を揃えた正確な比較、不一致箇所の可視化、および該当レコードへのダイレクトなアクセスを提供し、データ管理の精度向上を支援します。

## 主な機能

### 1. プロファイルベースの設定管理
- **複数設定の保存**: 比較対象のアプリや集計項目が異なる複数の設定を「プロファイル」として保存し、簡単に切り替えて運用できます。
- **柔軟なフィールドマッピング**: 自アプリの特定のフィールドと、別アプリの特定のフィールドをペアとして複数登録し、一度に比較することが可能です。

### 2. インテリジェントなデータ照合
- **期間一致ロジック**: 自アプリ・別アプリ双方に「日付フィールド」を指定することで、年月単位で集計期間を完全に一致させた比較が可能です。
- **キーフィールド照合**: 物件コードやIDなどの「突合キー」を使い、複数のレコードが存在する場合でも正確に集計・合算して比較します。

### 3. 表示対象の絞り込み機能 [NEW]
- **柔軟なフィルタリング**: 突合実行時に以下の条件で表示内容を絞り込むことができます。
    - **差額が出ている全てを表示**: 差分が発生している全ての項目を表示します。
    - **「自」のレコードのみしか存在していないもの**: 自アプリにのみレコードがあり、別アプリにないものを抽出します。
    - **「別」のレコードのみしか存在していないもの**: 別アプリにのみレコードがあり、自アプリにないものを抽出します。
    - **「自」「別」のどちらにもレコードが存在しているが差額で出ているもの**: 両方にレコードがあり、値が一致しないもののみを表示します。

### 4. 直感的なユーザーインターフェース
- **ダイアログ実行**: レコード一覧画面の「🔍 値比較を実行」ボタンからプロファイル、年月、絞り込み条件を選択して実行します。
- **日本語による進捗表示**: データ取得・照合中のステータスが日本語で表示され、処理状況を把握しやすくなっています。
- **高機能結果オーバレイ**: 比較結果は専用のテーブルで表示され、不一致箇所は赤字で強調されます。

### 5. 効率的な調査・修正支援（ジャンプ機能）
- **レコード直結リンク**: 結果テーブル内の「ジャンプ」列の「自」「別」ボタンから、それぞれの該当レコードへ直接アクセスできます。

## 使用方法

### 1. 設定
- プラグイン設定画面で、比較したいアプリや項目のマッピングを定義した「プロファイル」を作成します。

### 2. 実行
- レコード一覧画面の「🔍 値比較を実行」ボタンをクリックし、ダイアログから対象年月と**絞り込み条件**を選んで「突合実行」を押します。

### 3. 確認・調査
- 表示された結果テーブルで差分を確認し、必要に応じて「自」「別」ボタンから元レコードを修正します。
