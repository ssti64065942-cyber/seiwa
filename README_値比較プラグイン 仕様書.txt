# 値比較プラグイン 仕様書

## 概要

自アプリ（現在のアプリ）と別アプリの間で、共通のキー（物件コード等）を基に数値データ（売上、点検結果など）を照合・比較するためのプラグインです。集計期間を揃えた正確な比較、不一致箇所の可視化、および該当レコードへのダイレクトなアクセスを提供し、データ管理の精度向上を支援します。

## 主な機能

### 1. プロファイルベースの設定管理
- **複数設定の保存**: 比較対象のアプリや集計項目が異なる複数の設定を「プロファイル」として保存し、サイドバーで簡単に切り替えて運用できます。
- **柔軟なフィールドマッピング**: 自アプリの特定のフィールドと、別アプリの特定のフィールドをペアとして複数登録し、一度に比較することが可能です。

### 2. インテリジェントなデータ照合
- **期間一致ロジック**: 自アプリ・別アプリ双方に「日付フィールド」を指定することで、年月単位で集計期間を完全に一致させた比較が可能です。
- **キーフィールド照合**: 物件コードやIDなどの「突合キー」を使い、複数のレコードが存在する場合でも正確に集計・合算して比較します。

### 3. 直感的なユーザーインターフェース
- **ダイアログ実行**: レコード一覧画面の「🔍 値比較を実行」ボタンから、プロファイルと年月を選択するだけで素早く実行できます。
- **高機能結果オーバレイ**: 比較結果は専用のオーバレイテーブルで表示されます。不一致（差分）がある箇所は赤字で強調され、一目で問題を発見できます。

### 4. 効率的な調査・修正支援（ジャンプ機能）
- **レコード直結リンク**: 結果テーブル内の「ジャンプ」列に配置された「自」「別」ボタンから、それぞれのアプリの該当レコード詳細画面を別タブで直接開くことができます。
- **物件名の表示**: 突合キー（コード）に加えて物件名を表示できるため、視覚的に対象を把握しやすくなっています。

## プラグイン設定項目

### プロファイル基本設定
- **プロファイル名**: 設定を識別するための名称。
- **比較対象アプリID**: 照合先となる別アプリのID。
- **日付フィールド（自/別）**: 集計期間を特定するための日付・日時フィールド。

### 突合設定
- **物件名フィールド（自/別）**: 結果画面に表示する名称用フィールド（任意）。
- **キーフィールド（突合キー）**: レコードを特定・紐付けるためのフィールド（物件コード等）。

### 比較項目（フィールドマッピング）
- **表示ラベル**: 結果テーブルの行名となる名称。
- **自アプリ/別アプリの指定フィールド**: 比較対象となる数値や計算フィールド。

## 使用方法

### 1. 設定
- プラグイン設定画面で、比較したいアプリや項目のマッピングを定義した「プロファイル」を作成します。

### 2. 実行
- レコード一覧画面の右上にある「🔍 値比較を実行」ボタンをクリックし、ダイアログから対象年月を選んで「突合開始」を押します。

### 3. 確認・調査
- 表示された結果テーブルで差分を確認します。「自」「別」ボタンを活用して、不一致の原因となっているレコードを調査・修正します。
