# 駐車場売上目標登録プラグイン 仕様書

## 概要
年度 × 物件ごとの **売上目標(ALL)・年額**、**4月〜3月の月別目標**、および **担当履歴（適用開始月・管理部署・当社担当者）** を「売上指標マスタアプリ」で一元管理するための kintone プラグインです。
前年度の売上実績（現行の売上レコードアプリ155 ＋ 過去データの売上アプリ177 の期間オーバーラップ統合対応）× 倍率での**年度目標の一括初期生成**に加え、登録済み目標の**管理部署・担当者別での一覧抽出**、**前年度売上実績を見ながらの年額・月別目標（特需月の個別指定＆残月自動均等割り）の調整**、さらに担当者への確認・記入依頼に使える **Excel出力／Excel取込** までをワンストップで提供します。

---

## 主な機能

### 1. ✏️ 登録済み目標の一括修正・Excel出力/取込（メインタブ）
- **柔軟な絞り込み検索**:
  - 「年度」「管理部署」「当社担当者」「キーワード（物件コード・物件名）」「目標0円のみ」「変更ありのみ」を組み合わせて、対象社員・対象部署の物件をリアルタイムに一覧抽出できます。
  - 「表示中を全選択」「選択解除」ボタンで、絞り込んだ物件にワンクリックで一括チェックを入れられます。
- **前年度売上実績（年間＋月別）の参考表示**:
  - `売上目標(ALL)・年額` のすぐ左隣に **「前年度売上実績（参考）」** 列を表示します。
  - さらに 4月〜3月の各月目標入力欄の下にも **「前年同月の売上実績」** を参考表示するため、前年の実績を見ながら目標値を入力できます。
- **4月〜3月の月別目標調整（パターン2：年額固定＋特定月指定による残月自動均等割り）**:
  - 通常は年額目標の12等分（端数は最終月調整）が自動セットされます。
  - 12月や1月など売上が強い月の金額を直接入力・変更すると、その月に **`📌`（個別指定・青枠）** が付き、**`売上目標(ALL)・年額` は固定したまま、個別指定した月の合計を差し引いた残額が、残りの未指定月（例: 残り10か月）へ自動で均等割り**されます。
  - 各月の「解除」ボタン、または「均等割りに戻す」ボタンでいつでも通常の12等分に戻せます。
- **📊 Excel出力（表示中） / 📥 Excel取込**:
  - **📊 Excel出力（表示中）**: 現在絞り込まれている一覧を `.xlsx` ファイルとしてワンクリックでダウンロードできます（`年度`、`物件コード`、`物件名`、`前年度売上実績(参考)`、`売上目標(ALL)・年額`、`4月目標`〜`3月目標`、`適用開始月`、`管理部署`、`当社担当者`、`これまでの担当履歴(参考)`）。
  - **📥 Excel取込**: 担当者が記入した `.xlsx` ファイルを読み込むと、`物件コード` をキーに突合して画面に一括反映します。Excel 上で特定の月（例: 12月目標・1月目標）の金額を書き換えて取り込んだ場合も、自動的にパターン2（変更された月を📌固定し、年額からの残額を残りの月へ自動均等割り）が適用されます。
- **選択物件への一括操作パネル**:
  - **① 担当履歴の一括追加**: `適用開始月`・`管理部署`・`当社担当者` を指定して「＋ 選択物件に履歴追加」を押すと、チェックした全物件の担当履歴テーブル末尾に新しい履歴行が一括追加されます（空欄にした部署または担当者は、各物件の直近履歴行の値を自動引き継ぎ）。
  - **② 年額目標の一括変更**: 「指定金額にする（円）」「現在の年額に倍率を掛ける（倍）」「前年度売上実績に倍率を掛ける（倍）」の3モードで一括反映できます。
- **差分一括保存**:
  - 変更があったレコードのみを自動検知して黄色でハイライトし、右下の「**💾 変更を一括保存（N件）**」ボタンで100件ずつ分割して一括保存（`PUT /k/v1/records`）します。

### 2. 🎯 年度目標の一括生成（初期登録タブ）
- 対象年度の目標レコードが **1件も存在しない場合のみ** 実行可能です。
- **過去データアプリ統合集計**:
  - 過去データの売上アプリ（既定 ID: `177`、`2020-01-01`〜`2026-03-31`）と現行の売上レコードアプリ（既定 ID: `155`、`2026-04-01`〜）の期間オーバーラップ判定（`getOverlap`）により、前年度期間（例: `2025-04-01`〜`2026-03-31`）の売上実績を両アプリから自動取得・合算します。
- `前年度売上実績 × 設定倍率` に端数処理を適用して初期の年額目標および4月〜3月の月別目標を算出し、プレビュー確認後に一括登録します。

### 3. 操作性・画面表示の最適化
- **ウィンドウ全画面最大化（`□` / `❐` ボタン・ヘッダーダブルクリック）**: ブラウザ画面全体（`100vw × 100vh`）への最大化とサイズ復元をワンクリックで切り替えられます（状態は `localStorage` に自動保存）。
- **文字・数字サイズの拡大（`🔍 文字拡大` ボタン）**: 表の数値や入力ボックス・ラベルの文字サイズを大きく太く切り替えられます（状態は `localStorage` に自動保存）。

### 4. プラグイン設定画面（プルダウン自動選択＆12か月フィールド自動作成機能）
- 連携アプリ（現行売上アプリ・過去売上アプリ・物件マスタアプリ）および各フィールドをすべてプルダウンで選択でき、アプリ選択時にフィールド名・既定コードから**自動マッピング**されます。
- **「✨ 4月〜3月の12フィールドをこのアプリに自動作成する」ボタン**:
  - 売上指標マスタアプリに `4月目標`〜`3月目標`（`数値_4月目標`〜`数値_3月目標`）の12個の数値フィールドをワンクリックで自動作成し、プルダウンに自動セットします。

## 売上指標マスタアプリのフィールド構成

| 項目 | 既定フィールドコード（またはラベル名） | 型 | 備考 |
| :--- | :--- | :--- | :--- |
| 年度 | `数値_年度`（または `年度`） | 数値 | 開始年表記（例: 2026年度 = 2026/4/1〜2027/3/31） |
| 物件コード | `数値_物件コード`（または `物件コード`） | 数値 | アプリ148/155/177のキー |
| 物件名 | `文字列_物件名`（または `物件名`） | 文字列(1行) | |
| 売上目標(ALL)・年額 | `数値_売上目標_ALL`（または `売上目標(ALL)`） | 数値 | 年額（円） |
| 4月目標〜3月目標 | `数値_4月目標`〜`数値_3月目標` | 数値 | 各月の目標金額（設定画面のボタンで自動作成可能） |
| 月別目標（任意） | `数値_月別目標`（または `月別目標`） | 数値 | 基準月別目標（未固定月の均等割額） |
| 最終月目標（任意） | `数値_最終月目標`（または `最終月目標`） | 数値 | 年度最終月の目標金額 |
| 担当履歴 | `テーブル_担当履歴`（または `担当履歴`） | テーブル | 下記3項目を含むサブテーブル |
| └ 適用開始月 | `日付_適用開始月`（または `適用開始月`） | 日付 | 例: `2026-04-01`、`2026-10-01` |
| └ 管理部署 | `文字列_管理部署`（または `管理部署`） | 文字列(1行) | |
| └ 当社担当者 | `文字列_当社担当者`（または `当社担当者`） | 文字列(1行) | |
