# 絞り込み検索プラグイン

## 概要
マスタアプリと連携して、複数条件での絞り込み検索を実現するkintoneプラグインです。

## 主な機能
- ✅ マスタアプリとの連携
- ✅ 期間検索（開始日・終了日）
- ✅ 名称・コードでのオートコンプリート検索
- ✅ 任意の数の絞り込み条件（設定画面で自由に追加・削除可能）
- ✅ 検索条件の自動保存・復元（JSON方式による堅牢な保存）
- ✅ 汎用的な設定で様々なアプリに対応

## ファイル構成
```
plugin/
├── manifest.json       # プラグイン設定ファイル
├── desktop.js          # 本体JavaScript
├── config.html         # 設定画面HTML
├── config.js           # 設定画面JavaScript
├── icon.png            # アイコン画像（48x48px）
└── README.md           # このファイル
```

## インストール方法

### 1. プラグインファイルの準備
上記ファイルをZIP形式で圧縮します。

```bash
zip -r filter-search-plugin.zip manifest.json desktop.js config.html config.js icon.png
```

### 2. kintoneへのアップロード
1. kintone管理画面 → プラグイン
2. 「読み込む」ボタンからZIPファイルをアップロード
3. プラグインを有効化

### 3. アプリへの適用
1. 対象アプリの設定画面を開く
2. 「プラグイン」タブ → このプラグインを追加
3. 設定ボタンをクリックして各項目を設定

## 設定方法

### マスタアプリ設定
| 項目 | 説明 | 必須 |
|------|------|:----:|
| マスタアプリ | 検索対象となるマスタデータのアプリ | ⭕ |
| マスタ名称フィールド | 物件名など、検索時に表示する名称 | ⭕ |
| マスタコードフィールド | 一意に識別するためのコード | ⭕ |

### 絞り込み条件設定
「＋ 絞り込み条件を追加」ボタンで、必要な数だけ条件を増やせます：
- **対象アプリのフィールド**: マスタデータと連動させたいフィールド
- **表示ラベル**: 検索画面に表示される条件名

各行の右側にある「削除」ボタンで、不要な条件を削除できます。

### 対象アプリ設定
| 項目 | 説明 | 必須 |
|------|------|:----:|
| 対象名称フィールド | ルックアップなど、名称が入るフィールド | ❌ |
| 対象コードフィールド | マスタのコードと紐づくフィールド | ⭕ |
| 日付フィールド | 期間検索に使用する日付フィールド | ⭕ |

### 表示設定
| 項目 | 説明 | デフォルト値 |
|------|------|-------------|
| ボタンテキスト | 一覧画面に表示されるボタンのラベル | 🔍 絞り込み検索 |

## 使い方

### 1. 絞り込み検索の実行
1. レコード一覧画面で「🔍 絞り込み検索」ボタンをクリック
2. 検索条件を入力
   - **期間選択**: 開始日・終了日を指定
   - **名称検索**: オートコンプリートで候補から選択
   - **条件1〜3**: プルダウンから選択
3. 「絞り込み実行」ボタンをクリック

### 2. 条件のクリア
「条件クリア」ボタンで全ての絞り込みをリセットできます。

## 技術仕様

### 対応フィールドタイプ

**マスタアプリ:**
- 名称フィールド: 文字列（1行）
- コードフィールド: 数値
- 絞り込みフィールド: ドロップダウン、文字列（1行）

**対象アプリ:**
- コードフィールド: 数値
- 日付フィールド: 日付

### データ取得
- マスタアプリから500件ずつループで全件取得
- 初回読み込み時にメモリにキャッシュ

### 検索条件の保持
- `sessionStorage`を使用して検索条件を保持（ページリロード時も復元）
- プラグイン設定はJSONシリアライズ方式（`filterConfig`）で一括管理

## カスタマイズ例

### ボタンのスタイル変更
`desktop.js`の`createFilterButton()`関数内で、以下のCSSを編集：

```javascript
btn.style.cssText = `
    padding: 8px 16px;
    background: #3498db;  // ← 背景色
    color: white;         // ← 文字色
    ...
`;
```

### 絞り込み条件の管理
設定画面の「＋ 絞り込み条件を追加」ボタンから、上限なく条件を追加できます。
内部的にJSON形式で保存されるため、項目の増減によるデータの不整合が発生しません。

## トラブルシューティング

### プラグインが動作しない
- ブラウザのコンソールでエラーを確認
- 必須項目がすべて設定されているか確認
- マスタアプリのアクセス権限を確認

### マスタデータが取得できない
- マスタアプリIDが正しいか確認
- フィールドコードが正しいか確認
- APIトークンの権限を確認（必要に応じて）

### 絞り込みが反映されない
- 対象コードフィールドの値がマスタと一致しているか確認
- クエリ文字列が正しく生成されているか確認（ブラウザのURLを確認）
