# ゴミ箱機能プラグイン 仕様書

## 概要

Kintoneの標準機能では提供されていない「レコードの一時消去（ゴミ箱）機能」を実現するプラグインです。誤削除からの復旧を可能にし、データ保全性を高めます。

## 主な機能

### 1. レコードのゴミ箱への移動
- 元のアプリのレコード詳細画面にボタンを追加
- クリックでレコードを指定したゴミ箱アプリへ移動
- 移動後、元のアプリからレコードを自動削除

### 2. レコードの復元
- ゴミ箱アプリのレコード詳細画面にボタンを追加
- クリックでレコードを元のアプリへ復元
- 復元後、ゴミ箱アプリからレコードを自動削除

### 3. データの完全コピー
- 全フィールドデータを保持
- 添付ファイルも含めて完全にコピー
- サブテーブル内のデータも対応

## プラグイン設定項目

### 基本設定
- **元のアプリ**: プラグインを適用するアプリを選択
- **ゴミ箱アプリ**: レコードの移動先となるアプリを選択

### フィールドマッピング
- 元のアプリとゴミ箱アプリのフィールド対応を設定
- 同じフィールドコードは自動でマッピング
- フィールドタイプが一致するものだけ選択可能

### ボタン設定
- **ゴミ箱へ移動ボタン**: 表示名をカスタマイズ可能（デフォルト: 「ゴミ箱へ移動」）
- **復元ボタン**: 表示名をカスタマイズ可能（デフォルト: 「元のアプリへ復元」）

### 追加フィールド設定（オプション）
- **削除日時フィールド**: レコードがゴミ箱に移動された日時を記録
- **削除者フィールド**: レコードを移動したユーザーを記録
- **元のレコードIDフィールド**: 元のアプリでのレコードIDを記録

## 対応フィールドタイプ

以下のフィールドタイプに対応しています：

- 文字列（1行）
- 文字列（複数行）
- 数値
- 計算
- ラジオボタン
- ドロップダウン
- チェックボックス
- 複数選択
- 日付
- 時刻
- 日時
- ユーザー選択
- 組織選択
- グループ選択
- 添付ファイル
- リンク
- サブテーブル

## ゴミ箱アプリの推奨設定

### 必須設定
- 元のアプリと同じフィールド構成にする
- フィールドコードを一致させると設定が簡単

### 推奨追加フィールド
1. **削除日時** (日時フィールド)
2. **削除者** (ユーザー選択フィールド)
3. **元のレコードID** (文字列1行フィールド)

### アクセス権設定
- プラグイン利用ユーザーに「レコード追加」「レコード編集」「レコード削除」権限を付与
- 一般ユーザーには「レコード閲覧」のみ、またはアクセス制限を検討

## 使用方法

### 初期設定
1. ゴミ箱用のアプリを作成（元のアプリと同じフィールド構成）
2. プラグインを元のアプリとゴミ箱アプリの両方にインストール
3. プラグイン設定画面で以下を設定：
   - 元のアプリとゴミ箱アプリを選択
   - 「フィールドを読み込む」ボタンをクリック
   - フィールドマッピングを確認・調整
   - ボタン表示名を設定（必要に応じて）
   - 追加フィールドを設定（オプション）
   - 「保存」ボタンをクリック
4. アプリを更新

### レコードをゴミ箱へ移動
1. 元のアプリでレコード詳細画面を開く
2. 「ゴミ箱へ移動」ボタンをクリック
3. 確認ダイアログで「OK」をクリック
4. レコードがゴミ箱アプリへ移動され、元のアプリから削除される

### レコードを復元
1. ゴミ箱アプリでレコード詳細画面を開く
2. 「元のアプリへ復元」ボタンをクリック
3. 確認ダイアログで「OK」をクリック
4. レコードが元のアプリへ復元され、ゴミ箱アプリから削除される

## 注意事項

### 権限について
- 両アプリに対して「レコード追加」「レコード編集」「レコード削除」権限が必要
- 添付ファイルがある場合は「ファイル操作」権限も必要

### フィールドについて
- ルックアップ、関連レコード一覧は値のみコピーされ、連携設定は引き継がれない
- 復元後、レコードIDが変わるため参照関係は再設定が必要

### パフォーマンス
- 大量の添付ファイルがある場合、処理に時間がかかる可能性がある
- 処理中は画面を閉じないでください

### データ整合性
- ゴミ箱への移動と削除は1つのトランザクションではない
- ネットワークエラー等で処理が中断した場合、データが重複する可能性がある

## 対応環境

- PC版Kintone
- モバイル版Kintone

## トラブルシューティング

### アプリ一覧が表示されない
- ブラウザのキャッシュをクリア
- プラグインを再インストール

### レコードの移動・復元に失敗する
- アクセス権限を確認
- フィールドマッピングが正しいか確認
- ブラウザのコンソールでエラー内容を確認

### 添付ファイルがコピーされない
- ファイルサイズ制限を確認
- ファイル操作権限があるか確認

## サポート

エラーが発生した場合は、ブラウザの開発者ツール（F12）でコンソールログを確認し、エラー内容を記録してください。
