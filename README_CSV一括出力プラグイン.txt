# CSV一括出力プラグイン 仕様書

**バージョン:** 1.0  
**作成日:** 2026年1月15日  
**対象:** Kintone アプリ

---

## 1. 概要

### 1.1 プラグインの目的
Kintoneアプリのレコード一覧画面から、全レコードまたは絞り込まれたレコードをCSVファイルとして一括出力するプラグインです。

### 1.2 主な機能
- レコード一覧画面にCSV出力ボタンを追加
- 大量データ（500件以上）の自動ページング取得
- 出力フィールドの選択機能
- システムフィールドの除外オプション
- テーブルフィールドの出力形式選択
- ファイル名のカスタマイズ
- Excel対応（BOM付きUTF-8）

---

## 2. 動作環境

### 2.1 対応環境
- **Kintone:** クラウド版
- **ブラウザ:** Chrome、Edge、Firefox、Safari（最新版）
- **デバイス:** PC、タブレット

### 2.2 必要な権限
- アプリの「レコード閲覧」権限

---

## 3. 機能仕様

### 3.1 CSV出力ボタン

#### 表示位置
レコード一覧画面のヘッダーメニュースペース

#### ボタンデザイン
- **ラベル:** 📥 CSV出力
- **色:** 青色（#3498db）
- **状態:**
  - 通常: クリック可能
  - 処理中: グレーアウト、「⏳ 処理中...」表示

#### 動作
1. ボタンクリック
2. レコード取得開始（プログレス表示）
3. CSV生成
4. ファイルダウンロード
5. 完了メッセージ表示（3秒後に自動非表示）

---

### 3.2 レコード取得仕様

#### 取得対象
- 現在の絞り込み条件が適用されたレコード
- 一覧画面で表示されているレコードのみ（権限による制限あり）

#### ページング
- 1回のAPI呼び出しで最大500件取得
- 500件を超える場合は自動的に複数回に分けて取得
- 取得進捗をリアルタイム表示

#### 取得フィールド
- 設定画面で選択されたフィールドのみ
- 未選択の場合は全フィールド

---

### 3.3 CSV出力仕様

#### ファイル形式
- **形式:** CSV（カンマ区切り）
- **文字コード:** UTF-8（BOM付き）
- **改行コード:** CRLF（\r\n）
- **拡張子:** .csv

#### ファイル名
```
[プレフィックス]_app[アプリID]_[タイムスタンプ].csv
```

**例:**
```
kintone_export_app123_20260115_143025.csv
```

#### ヘッダー行
- 1行目: フィールドコード
- 例: `顧客名,金額,作成日時`

#### データ行
- 2行目以降: レコードデータ
- ダブルクォート、カンマ、改行を含む値は自動的にエスケープ

---

### 3.4 フィールドタイプ別の出力形式

| フィールドタイプ | 出力形式 | 例 |
|---|---|---|
| 文字列（1行） | そのまま出力 | `山田太郎` |
| 文字列（複数行） | そのまま出力（改行含む） | `"住所1\n住所2"` |
| 数値 | 数値 | `1000` |
| 日付 | YYYY-MM-DD | `2026-01-15` |
| 日時 | ISO 8601形式 | `2026-01-15T14:30:00Z` |
| ドロップダウン | 選択値 | `承認済み` |
| チェックボックス | カンマ区切り | `オプションA, オプションB` |
| ラジオボタン | 選択値 | `はい` |
| ユーザー選択 | ユーザー名 | `山田太郎` |
| 組織選択 | 組織コード | `sales_dept` |
| 添付ファイル | ファイル名 | `document.pdf` |
| テーブル | 行数 or JSON | `3行` or `[{...}]` |
| リンク | URL | `https://example.com` |
| 計算 | 計算結果 | `15000` |

## 4. 設定画面仕様

### 4.1 出力フィールド選択

#### 表示内容
- アプリ内の全フィールドをチェックボックスで表示
- フィールド名とフィールドタイプを表示
- システムフィールドは下部に表示

#### 操作
- **すべて選択:** 全フィールドにチェック
- **すべて解除:** 全フィールドのチェックを外す
- **個別選択:** 各フィールドを個別にチェック/解除

#### デフォルト
- 初回設定時: 全フィールド選択
- 2回目以降: 前回の設定を保持

---

### 4.2 ファイル名プレフィックス

#### 設定項目
- **項目名:** ファイル名のプレフィックス
- **入力形式:** テキスト（半角英数字推奨）
- **デフォルト値:** `kintone_export`
- **例:** `sales_data` → `sales_data_app123_20260115_143025.csv`

---

### 4.3 システムフィールド除外

#### 設定項目
- **項目名:** システムフィールドを除外する
- **形式:** チェックボックス
- **デフォルト:** オフ

#### 対象フィールド
- レコード番号（$id）
- リビジョン（$revision）
- 作成者
- 作成日時
- 更新者
- 更新日時

---

### 4.4 テーブルフィールドの出力形式

#### 設定項目
- **項目名:** テーブルフィールドの出力形式
- **形式:** ラジオボタン
- **選択肢:**
  - **簡易形式（行数のみ）:** `3行`（デフォルト）
  - **JSON形式（全データ）:** `[{"value":{"フィールド1":{"value":"値1"}}}]`

---

## 5. 使用方法

### 5.1 初期設定

1. Kintone管理画面 → プラグイン → プラグインをアップロード
2. 対象アプリの設定 → プラグイン → CSV一括出力プラグインを追加
3. 歯車アイコンをクリックして設定画面を開く
4. 出力したいフィールドを選択
5. その他の設定を調整
6. 「保存」をクリック
7. アプリを更新

### 5.2 CSV出力手順

1. レコード一覧画面を開く
2. 必要に応じて絞り込み条件を設定
3. 「📥 CSV出力」ボタンをクリック
4. 処理完了を待つ
5. CSVファイルが自動ダウンロード

---

## 6. 制限事項

### 6.1 技術的制限
- **最大レコード数:** Kintone APIの制限に準拠（通常10,000件まで）
- **タイムアウト:** 大量データの場合、ブラウザのタイムアウトが発生する可能性あり
- **同時実行:** 複数ユーザーが同時に実行可能だが、各ユーザーは1回ずつ

### 6.2 機能的制限
- **定期実行不可:** 手動実行のみ（自動・定期実行は不可）
- **保存先指定不可:** ブラウザのダウンロードフォルダに保存
- **OneDrive直接保存不可:** ダウンロード後に手動で移動が必要

### 6.3 権限による制限
- ユーザーが閲覧権限を持つレコードのみ出力可能
- フィールドの閲覧権限がない場合、そのフィールドは空欄で出力

## 7. トラブルシューティング

### 7.1 ボタンが表示されない

**原因:**
- プラグインが正しくインストールされていない
- ブラウザキャッシュが残っている

**対処法:**
1. アプリを更新
2. Ctrl + F5 で強制リロード
3. プラグインを再インストール

---

### 7.2 CSV出力が途中で止まる

**原因:**
- ネットワークエラー
- APIレート制限

**対処法:**
1. ネットワーク接続を確認
2. 時間をおいて再実行
3. 絞り込み条件で件数を減らす

---

### 7.3 文字化けする

**原因:**
- Excelで開く際の文字コード認識エラー

**対処法:**
1. CSVファイルを右クリック → プログラムから開く → メモ帳
2. 名前を付けて保存 → エンコード: UTF-8
3. 再度Excelで開く
