# 日別売上帳票出力プラグインv2 仕様書

## 概要

kintoneに蓄積された日々の売上データと、管理会計アプリなどの「マスタデータ」を結合し、見やすいカレンダー形式の「日別売上帳票（Excelファイル）」として一括出力・ダウンロードできるプラグインです。
プロファイル機能を用いた定期的な一括出力や、出力フォーマットの柔軟なカスタマイズに対応しており、日々の集計や月次報告業務を大幅に効率化します。

## 主な機能

### 1. 柔軟なExcel出力フォーマット
- **動的カラムマッピング**: Excelの任意の列（A列、B列など）に対して、kintoneのどの数値を割り当てるかを自由に設定できます。
- **日次合計の自動計算**: 設定した複数の数値フィールドの合計値を自動で算出し、「日次合計列」として任意の列に出力可能です。
- **休日カラーリング設定**: 休日APIと連動し、土曜日や日祝日の行（日付）の背景色を自動で色付けします（設定画面から色や追加の休日を自由に指定可能）。
- **タイトル自動センタリング**: カラム数に応じて、Excelの一番上の「日別売上一覧」のタイトルが自動的に表の幅全体の中央に結合・配置されます。

### 2. プロファイル機能（物件の固定セット出力）
- **プロファイル管理**: 「関東エリア全店舗」「直営店のみ」など、よく出力する物件（店舗や駐車場など）の組み合わせに名前を付けて「プロファイル」として保存できます。
- **ワンクリック一括出力**: アプリのトップ画面からプロファイルを選択するだけで、設定された全物件の帳票を1つのZIPファイル（または複数シートのExcelファイル）として一括で生成・ダウンロードできます。

### 3. 個別選択・動的フィルタリング
- **条件による絞り込み出力**: ダッシュボードのように、任意の「追加検索条件」をプルダウンやテキストで指定し、対象の物件のみをリアルタイムに絞り込んで出力することができます。
- **チェックボックスによる選択**: 絞り込まれた物件の中から、さらに特定の物件だけをチェックして個別出力することが可能です。何もチェックせずに実行した場合は、現在の絞り込み条件に合致するすべての物件が出力されます。

### 4. ゼロ件データの出力対応
- **データなし物件の出力**: 該当の月に売上データが1件も存在しない物件であっても、出力対象として選ばれていればスキップされず、すべての項目が「0円」として初期化されたシートが確実に出力されます。

### 5. リッチなUIと進捗可視化（プログレスバー）
- **直感的なダイアログ操作**: プラグインの設定画面だけでなく、アプリのトップ画面から呼び出す出力画面もタブ形式で整理されており、迷わず操作できます。
- **進捗のリアルタイム表示**: 大量の物件を出力する際でも、「データを集計中...」「Excel出力中...（〇件 / 〇件 完了）」といった進捗状況がプログレスバーでリアルタイムに可視化されるため、ユーザーにストレスを与えません。

## プラグイン設定項目

### 1. 基本連携設定
- **マスタアプリ連携**: 分析の軸となるマスタアプリ（物件・駐車場など）を指定し、売上データとの「検索キー（マスタのレコード番号、または物件コード）」を設定します。
- **表示用フィールド**: UI上に表示するための「物件名」や「物件コード」のフィールドを指定します。
- **追加検索条件**: ユーザーが出力時に絞り込みを行うための条件フィールドを無制限に追加できます。

### 2. フォーマット設定
- **Excelヘッダーと出力項目**: Excelの1行目に出力する独自のヘッダー情報（特定のセルに対する固定値やkintoneフィールドの値）と、カレンダー部分のマッピング（列とフィールドの紐付け）を設定します。複数のフォーマットを保存可能です。

### 3. プロファイル設定
- **プロファイル作成**: プラグイン設定画面上で、マスタアプリから物件を検索・選択し、独自のプロファイルとして保存します。
- **データ使用量の可視化**: Kintoneのプラグイン設定上限（256KB）に対して、現在の設定データがどの程度容量を消費しているか（パーセンテージとバー）を画面上部で常に確認できます。

### 4. システム設定
- 休日の背景色（土曜日、日祝日）のカラーコード指定。
- 独自の休業日や特別休日のリスト（改行区切り）の指定。

## 使用方法

### 1. 準備
- プラグイン設定画面を開き、「基本連携設定」と「フォーマット設定」を完了させます。
- 定期的に出力する物件が決まっている場合は、「プロファイル設定」からプロファイルを作成しておきます。
- 設定を「保存」し、アプリ設定画面で「アプリを更新」します。

### 2. 帳票の出力（アプリトップ画面）
- レコード一覧画面のヘッダーにある「📊 帳票一括出力v2」ボタンをクリックします。
- ダイアログが開き、「📝 個別選択」タブまたは「📁 プロファイル一括出力」タブを選択します。
- **個別選択の場合**: 追加検索条件で物件を絞り込み、対象月やフォーマットを選択して「実行」を押します。
- **プロファイルの場合**: 保存されているプロファイルを選び、「このプロファイルで出力」を押します。
- プログレスバーが100%になると、ブラウザのダウンロード機能でファイルが保存されます。
